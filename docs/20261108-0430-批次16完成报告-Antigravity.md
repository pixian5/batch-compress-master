## 2. 关键代码变更与架构实现

### 2.1 安全诊断脱敏导出服务 (`Core/Services/DiagnosticsExportService.cs`)
- **密码脱敏机制**：采用前置/边界约束的精准正则替换：
  1. `(--password\s+)("[^"]*"|\S+)` -> `$1"***"`
  2. `(^|\s)(-p)("[^"]*"|(?!\"\*\*\*\"|\s)\S+)` -> `$1$2"***"`
  3. `(^|\s)(-hp)("[^"]*"|(?!\"\*\*\*\"|\s)\S+)` -> `$1$2"***"`
  避免了单字符 `-p` 误伤 `--password` 的前缀漏洞，对普通命令参数（如 `-o`、`-v`、`-mx`）严格无误伤；
- **多代日志与 Gzip 支持**：从日志目录自动发现 `batchcompress_*.log*`（涵盖纯文本代次与历史 `.gz` 归档），对 `.gz` 自动在内存中经 `GZipStream` 解包、脱敏后再收入 zip 归档；
- **系统摘要清单**：自动输出 `diagnostics_summary.json`，包含应用版本（`VERSION`）、操作系统描述、OS/进程架构、.NET 运行时版本及归档引擎可用性状态，完全无需第三方包（BCL `System.IO.Compression.ZipArchive` 原生实现）；
- **CLI 原生接入**：`CommandLineHandler` 新增 `--export-diagnostics <zip路径>`，在 5 种语言帮助文本（zh-CN、zh-TW、en、ja、de）中同步呈现，德文保持严格 0 中文字符。

### 2.2 分卷子进度解析器 (`Core/Services/ArchiveSubProgressParser.cs`)
- **进度百分比提取**：`TryParsePercentage` 解析类似 ` 15% 3 + test.txt`、`Creating archive ... 98%` 等标准输出，严格钳制在 0 到 100 范围，非数值或无效文本安全回退 `null`；
- **分卷序号提取**：`TryParseVolumeNumber` 支持 7zz 风格（`.7z.001`）与 WinRAR 风格（`.part01.rar`）分卷编号提取；
- **模型演进**：`OperationProgressInfo` 扩充 `public int? SubProgressPercent { get; set; }`，向后完全兼容。

### 2.3 并发测试桩线程安全加固
- 在多线程高并发回归测试中，审查排查出 `ConcurrentTrackingEngine.CompressionInputs`、`ExtractionInputs` 以及 `SnapshotProgress` 内部直接调用非线程安全容器 `List<T>.Add()`，在极限并发下偶发产生并发写入冲突导致丢条目；
- 本次对相关测试辅助类增加互斥锁同步，实测 3 轮连续回归 68/68 项全部秒过，彻底扫清了并发断言偶发抖动的隐患。

# 复核问题修复

本次根据旧 WinForms 与当前 Avalonia 的功能对比，修复以下行为：

- “打开来源”统一使用当前页的来源目录；TXT 模式会优先打开其来源目录，不再把 TXT 文件路径误当作目录。
- “清空源”只清除当前压缩页或解压页的列表；“清空所有日志”才会清除两页列表和全部日志。
- 归档进程返回完整命令行。GUI 命令日志同时记录命令参数、stdout 和 stderr，密码参数按用户要求原样保留，不做脱敏、掩码或替换。
- 日志页移除外层框线，并将日志区域高度扩大到 580 像素，文本框自身保持无边框滚动显示。

回归验证覆盖完整命令日志和原始密码参数，且现有分卷、7zz、TXT 密码本、后处理冲突和命令行测试继续通过。

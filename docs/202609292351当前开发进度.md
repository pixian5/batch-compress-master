## B 批次：运行消息本地化（0.6.3）

目标：消除“中文界面混英文、英文界面混中文”，让界面语言切换后日志、通知与逐项状态消息同步变化。

1. **词条补齐**
   - `LanguageStrings` 与 `LocalizationService` 新增 48 个运行消息词条，覆盖 zh-CN、zh-TW、en、ja、de 五种语言；同时删除了从未被引用的 `CompletedMessage`。
   - 更新 `Warning7zFormat` 文案为更准确的“7z 使用官方 7-Zip；恢复记录、快速打开和 RAR 注释选项不会应用”。
2. **ViewModel 运行消息**
   - 页面限制提示、选项冲突、自动加载与空列表提示、完成统计、取消提示、错误提示、关机计划与取消关机、密码查询结果行、阶段性进度通知、文本清单导入诊断、7z 与存储模式提示、目录大小统计错误，全部改为读取 `L.*` 资源。
3. **服务层逐项状态**
   - `BatchOperationService` 中所有通过 `progress.Report()` 送达界面与命令行的消息（格式不支持、跳过已存在、开始压缩/解压、成功/失败/成功后处理失败、大小上限、无法解析、大小写歧义、分卷编号重复、分卷不完整）改为读取本地化资源。
   - 文件名、路径、错误原文等数据仍原样传入，不翻译。
4. **命令输出分类改为结构化标记**
   - `OperationProgressInfo` 新增 `IsCommandOutput`，`ReportArchiveOutput` 的三条消息携带该标记，ViewModel 不再用中文字符串前缀匹配来分类日志，命令前缀因此可以随语言变化。
5. **新增两条回归测试**
   - `英文与德语资源不含中文`：反射遍历全部字符串属性，en/de 任一属性含中文即失败，防止后续新增词条漏译。
   - `服务消息跟随界面语言`：把语言切到 en 后走真实调用链，断言分卷不完整消息取自英文资源且整组消息不含中文。

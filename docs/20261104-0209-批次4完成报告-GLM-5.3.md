### 2.3 日志安全与体积治理（FileLoggerService）

- **0600 权限**：`InitializeWriter` 创建/打开日志后调用 `RestrictLogFilePermissions`——
  非 Windows 平台 `File.SetUnixFileMode(UserRead | UserWrite)`；失败仅告警不影响日志功能。
  动机：日志按用户要求**原样保留命令行（含 `-p<密码>`）**，必须防同机他用户读取
  （默认 umask 022 下的 0644 是实际风险，冒烟中旧日志 `-rw-r--r--` → 新日志 `-rw-------`）。
- **轮转**：`rotationBytes`（默认 10MB）可在构造时覆写（测试用小阈值）；每次写入后计数，
  每 64 次写入在锁内检查大小，超限则当前文件改名为 `.1`（旧 `.1` 先删，只保留一代），
  新建同名文件继续写；轮转失败尽力恢复不影响主流程。CLI 与 GUI 共用此服务，同时受益。
- **过期清理**：会话启动时删除日志目录内匹配 `batchcompress_*.log` / `*.log.1`
  且最后写入早于 7 天的文件；用户显式指定的其它命名不受影响（测试锁定）。
- `ArchiveProcessRunner` 本身不写文件（进程边界，输出经服务层进入日志器），
  0600/轮转落在 FileLoggerService 即完整覆盖指令所指范围。

### 2.4 CLI 解析期错误本地化

- **词条**：31 条 `CliError*` 词条注入 `LanguageStrings` 默认值与五个语言工厂
  （脚本化生成，zh-CN 与原硬编码**逐字一致**保证既有中文断言零回归；
  en/de 为纯西文——既有“英文与德语资源不含中文”扫描测试自动覆盖新词条）。
- **语言生效时机**：`ParseArguments` 开始即 `DetectLanguage` 预扫描——
  `--lang` 出现在出错参数**之后**也生效（`compress --level x --lang en` 报英文，
  测试锁定）；`Program.Main` 解析成功后仍统一同步一次，GUI 场景不受影响。
- **Program.cs**：`参数错误: {0}` 前缀与 `使用 --help 查看完整用法。` 提示
  一并接入词条（`CliErrorPrefix`/`CliErrorSeeHelp`），失败路径语言跟随 `--lang`。
- **zh-TW 帮助**：新增完整正体中文帮助文本（术语与简体版逐节对应：
  批次壓縮/封存/圖形介面/復原記錄等），`ShowHelp` 三语映射（zh-CN/zh-TW/en，
  ja/de 回退英文）。

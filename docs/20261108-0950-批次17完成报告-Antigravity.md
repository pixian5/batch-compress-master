## 2. 关键代码变更与架构实现

### 2.1 归档进程输出流式监听与字符级无损保证 (`Core/Services/ArchiveProcessRunner.cs`)
- **双模读取机制**：
  - 当 `onOutputLine == null` 时，直接执行 `reader.ReadToEndAsync()`，保持历史零开销读取；
  - 当 `onOutputLine != null` 时，通过缓冲块异步读取，字符级原样累加至 `StringBuilder`（彻底保全原始密码、路径与字符边界，表征测试 `TestProcessOutputAndArgumentBoundaries` 零漂移）；
  - 遇到 `\r` 或 `\n` 时，即时触发单行回调，捕获 7zz 控制台利用 `\r` 原地覆写的百分比刷新行（例如 ` 35%`、` 80%`）；
- **7-Zip 进度开关注入**：
  - `SevenZipCommandBuilder.cs` 在构建压缩（`a`）、解压（`x`）和测试（`t`）命令时注入官方 `-bsp1` 开关，确保管道重定向场景下官方 7zz 仍向 stdout 发送进度数据流。

### 2.2 批量执行管线子进度流式串联 (`Core/Services/Pipeline/BatchExecutionPipeline.cs`)
- **串行与并发双路径统一对接**：
  - 在 `RunSequentialAsync` 中，准备项生成后自动绑定 `item.Options.OutputLineHandler = line => ...`；
  - 在 `RunConcurrentAsync` 中，并发引擎输出的百分比变化在 `lock (gate)` 保护下安全更新 `progressInfo.SubProgressPercent`，并通过 `CloneProgress` 输出不可变快照，杜绝撕裂读；
  - 任务执行完毕后在 finally 逻辑中确定性将 `SubProgressPercent` 重置为 `null`，避免进度残留污染后续状态。

### 2.3 NDJSON 契约模式版本化 (`schemas/ndjson-schema-v1.json` & `NdjsonOutputWriter.cs`)
- `schemas/ndjson-schema-v1.json` 在 `summary` 顶层定义中增加强制必填字段 `"schemaVersion": { "type": "integer", "const": 1 }`；
- 在 `progress` 事件定义中增加可选字段 `"subProgressPercent": { "type": ["integer", "null"], "minimum": 0, "maximum": 100 }`；
- `NdjsonOutputWriter.cs` 同步支持分阶段 `phase` 识别：当存在子进度百分比时标记 `phase: "progress"`，无百分比时保持 `phase: "start"`，保证与老版本 CLI 消费者的绝对兼容。

### 2.4 GUI 诊断导出与双进度条沉浸式呈现 (`ViewModels/` & `Views/MainWindow.axaml`)
- **一键诊断导出**：
  - `MainWindowViewModel.Execution.cs` 新增 `ExportDiagnosticsAsync()`，调用 `DiagnosticsExportService` 自动将脱敏诊断包输出至系统桌面（`batchcompress-diagnostics-YYYYMMDD-HHmmss.zip`），并触发系统桌面通知与状态记录；
  - 主界面快捷操作区在清空命令后新增“导出诊断”按钮，带本地化 ToolTip；
- **双进度条展示**：
  - `Views/MainWindow.axaml` 状态栏下方新增响应式子进度条，绑定 `SubProgressPercent` 与 `HasSubProgress`；当归档引擎报告子任务进度时平滑呈现百分比，未报告或任务完成时自动折叠，不破坏原界面布局与紧凑度；
- **多语言完整性**：
  - `LanguageStrings.cs` 与 `LocalizationService.cs` 全量补充 5 语言字典（zh-CN、zh-TW、en、ja、de），德文与英文无中文残留，并通过扫描验证。

## 已确认限制

### 7z/ZIP 分卷开启 `--test`

分卷创建成功，但校验阶段仍使用不存在的基础归档路径，例如：

```text
7zz a ... -v1m .../大文件随机.bin.7z ...
7zz t .../大文件随机.bin.7z
ERROR: errno=2 : No such file or directory
```

因此脚本将 7z/ZIP 分卷 `--test` 的退出码 1 作为预期失败；关闭 `--test` 后创建和解压均通过。RAR 分卷开启 `--test` 通过。

### quiet 失败输出

错误密码配合 `--quiet` 返回退出码 1，错误完整写入日志，但当前 stdout/stderr 均为空，与帮助中“向 stderr 输出错误”的文案不一致。该行为已保留为测试证据，未在本轮擅自改变功能语义。

### 关机

只检查了 `--shutdown` 帮助和绑定，未执行真实关机；GUI 的“完成后关机”也未点击。

# 归档发布与界面状态修复

日期：2026-08-10

## 修复内容

- 命令行压缩来源在存在性检查后转换为绝对规范路径再去重，等价的 `a.txt` 与 `./a.txt` 不会重复创建归档。
- GUI 压缩格式统一经过格式目录规范化。`.7Z`、`gzip` 等别名生成 `7z`、`gz` 的规范输出扩展名。
- 压缩和解压标签页分别保存其完整选项状态，包括压缩级别、固实、分卷、RAR 专属选项、注释、临时目录和附件列表。
- 文件扫描与目录大小计算仍在后台执行；所有绑定属性和日志更新均回到 Avalonia UI 调度器，避免后台线程更新界面状态。
- 发布内容按 `RuntimeIdentifier` 选择 7zz 资源。交叉发布 `linux-x64` 时不会误携带 macOS 7zz。

## RAR 发布边界

公开仓库不再保存或发布 RAR/WinRAR 二进制、`rarreg.key` 或任何第三方授权资料。RAR 功能保留：运行时可使用系统安装的完整 `rar`，或设置 `BATCHCOMPRESS_RAR_PATH` 指向用户已获授权的可执行文件。macOS 私有打包可通过 `BATCHCOMPRESS_RAR_DIR` 注入 `rar` 与 `unrar`，默认打包不包含它们。

## 验证

- Release 构建和 25 项核心回归测试通过。
- 命令行全功能夹具新增等价路径去重断言。
- 发布验证检查 `linux-x64` 产物只包含 Linux 7zz 资源。

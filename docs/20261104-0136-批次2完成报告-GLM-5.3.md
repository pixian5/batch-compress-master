### 2. OperationSession 设计

- **会话生命周期**（`RunAsync(operationLabel, completeTitle, execute)`）：
  `IsOperating=true → ResetCounters → 会话状态初始化 → BeginOperationCancellation → execute(token)`
  →（返回非 null 时）`OfferShutdownCancellationAsync → 完成汇总日志 → 完成通知`；
  `OperationCanceledException → 取消标题+通知`；`Exception → OperationError`；
  `finally → IsOperating=false、CurrentSourcePath 清空、EndOperationCancellation`。
  execute 返回 `null` 对应原实现的"无事可做提前 return"（跳过汇总但仍走 finally 清理）。
- **统一进度回调**（`CreateProgress`/`HandleProgress`）：九项统计回写、
  `ElapsedTime`、MB/s 速度、剩余时间与预计完成时刻、`MaybeShowProgressNotification`
  （首个完成项/每 10 项/每 GB/每 5 分钟节流，状态随会话实例重置）、
  基于 `IsCommandOutput`/`IsError` 的三分类日志。
- **差异点参数化**：操作标签与完成词条以 `Func<string>` 传入，
  保持原实现"每次使用时求值"的语言切换语义（运行中切换语言时通知/取消文案仍取当前资源）。
- **取消令牌托管**：VM 新增 `BeginOperationCancellation`/`EndOperationCancellation`
  internal 辅助，取消命令（`CancelOperation`）仍经 VM 字段访问在途令牌，行为不变。

### 架构收敛成果

- **服务层**：双循环下沉为 `IBatchItemAdapter`＋`BatchExecutionPipeline` 共性骨架，
  条目差异归适配器；后处理策略归 `PostProcessService`；门面仅剩公共 API 与目录扫描。
- **来源层**：GUI/CLI 共用 `SourceCollector`（规范化/过滤/去重/密码本配对/首卷折叠），
  尾部斜杠缺陷在四个出口统一封堵。
- **界面层**：进度回调与操作生命周期归 `OperationSession`，两个命令方法只剩来源收集与选项快照。

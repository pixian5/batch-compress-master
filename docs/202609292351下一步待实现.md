## 中优先级

4. **旧式分卷识别**
   - `ArchiveVolumeResolver` 只识别 `.partN.rar`、`.7z.N`、`.zip.N`、`.<ext>.N`；目录扫描遇到 `xxx.r00`、`xxx.z01`（`ArchiveFormatCatalog` 中已有别名）会作为独立单卷任务进入解压并失败，污染成功/失败统计。需要补充识别或显式跳过并提示。
5. **CI 与测试基建**
   - 仓库暂无 `.github/workflows`。建议增加 Windows/macOS/Linux 三平台矩阵工作流，执行 `dotnet build` 与测试控制台，保证每次推送不破坏构建。
   - 测试项目目前只链接 Core 与 CLI，`MainWindowViewModel` 的列表解析、选项映射、标签状态保存等纯逻辑没有自动化覆盖。
6. **GUI 与 CLI 来源收集逻辑统一**
   - `HeadlessBatchRunner.CollectCompressionSources` 与 ViewModel 的列表解析是两套实现，容易在密码本模式、格式匹配规则上产生语义漂移，建议下沉到 `BatchOperationService` 统一。

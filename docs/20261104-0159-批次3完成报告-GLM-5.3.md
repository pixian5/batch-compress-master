## 2. CLI 语言支持

- **解析**：`--language`（别名 `--lang`）Single 值选项；`NormalizeLanguage` 把
  `zh/zh-CN/zh-Hans→zh-CN`、`zh-TW/zh-Hant/tw→zh-TW`、`en/en-US→en`、`ja/ja-JP→ja`、
  `de/de-DE→de` 归一到 `LocalizationService` 语言键；未知值报参数错误（退出码 2）。
- **同步时机**：`Program.Main` 在**完整解析成功后立刻**设置
  `LocalizationService.Instance.CurrentLanguage`，随后无界面运行期所有服务层消息
  （开始压缩/成功/跳过/缺卷等）与 CLI 输出同语言——混搭问题消除。
- **帮助语言**：`--help` 不经过完整解析，新增 `DetectLanguage(args)` 预扫描
  （支持 `--lang en` 与 `--lang=en`）选择帮助文本；未指定/无效回退中文默认。
- **帮助文本**：中文原文补记 `--language`/`--output-format` 两节；新增完整英文帮助
  `EnglishHelpText`。zh-TW 暂用简体文本、ja/de 帮助回退英文（任务书允许“至少中英双语”）。

## 3. NDJSON 结构化输出（--output-format json）

- **别名冲突说明**：`--format` 是 `--extension` 的历史别名（有测试与兼容性锁定），
  故输出格式仅使用 `--output-format`，未按任务书备选挪用 `--format`——已在中英帮助中注明。
- **事件分类**（`Core/Services/NdjsonOutputWriter.cs`，按进度快照计数增量判定）：
  - 计数未变的过程消息 → `{"type":"progress","phase":"start","source","message"}`；
  - Success/Fail/跳过类计数增加 → `{"type":"item","status":"success|fail|skip",…七类计数}`；
    归档成功但后处理失败 → status=success 且 `postProcessFailCount` 呈现；
  - 批次正常结束 → `{"type":"summary","success","failed","postProcessFailed","ignored",
    "nonexistent","incompleteVolumes","ambiguous","elapsedSeconds"}`（取消中止不输出）。
- **密码排除**：`IsCommandOutput` 事件（命令行/stdout/stderr 原文，含 `-p<密码>`）整条丢弃；
  服务层状态消息本身不含密码。测试断言密码串不出现在输出流。
- **流分离**：json 模式下 stdout 只承载 NDJSON；`Found/Completed/Log file` 等人类可读提示
  与 `--verbose` 行改写 stderr；`--quiet` 在两种模式下均静默人类提示。
- **编码**：`System.Text.Json`＋`UnsafeRelaxedJsonEscaping`（中文原样、仍为合法 JSON），
  逐行 Flush 保证流水线消费。
- **退出码**：0/1/2/130 映射保持原样（真实冒烟验证 0 与 2）。

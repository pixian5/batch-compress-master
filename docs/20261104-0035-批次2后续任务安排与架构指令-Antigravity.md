## 1. 任务分解与执行清单

### 阶段 0：前置缺陷阻断与表征测试补强（P0，必须优先执行）
> 目标版本：`0.6.12`

- [ ] **任务 0.1：修复 `DescribeVolumeSuffix` 的多对一映射缺陷**
  - **位置**：`Core/Services/ArchiveVolumeResolver.cs`（L351-L358）
  - **缺陷**：`Math.Max` 截断使得 `number == 1`（主卷缺失）与 `number == 2`（首分卷缺失）均输出 `r00` 或 `z01`。
  - **修复要求**：
    ```csharp
    ArchiveVolumeKind.RarOldStyle => number == 1 ? "rar" : $"r{(number - 2).ToString("D2", CultureInfo.InvariantCulture)}",
    ArchiveVolumeKind.ZipOldStyle => number == 1 ? "zip" : $"z{(number - 1).ToString("D2", CultureInfo.InvariantCulture)}",
    ```
  - **测试断言**：在 `BatchCompress.Avalonia.Tests/Program.cs` 中增加对 `DescribeVolumeSuffix(res, 1)` 返回 `"rar"` / `"zip"` 的显式断言。

- [ ] **任务 0.2：阻断 `.z00` 与主卷编号撞车**
  - **位置**：`Core/Services/ArchiveVolumeResolver.cs`（L99-L101）
  - **缺陷**：第三方工具的 `.z00` 被匹配后偏移为 1，与主卷 `base.zip`（编号 1）产生重复编号，导致整个归档被误判为冲突分卷并跳过。
  - **修复要求**：正则增加负向前瞻，排除 `00`：
    ```csharp
    private static readonly Regex ZipOldStyleRegex = new(
        @"^(?<base>.+)\.z(?!00)(?<number>\d{2,})$",
        RegexOptions.IgnoreCase | RegexOptions.CultureInvariant);
    ```
  - **测试断言**：追加测试断言，同目录下存在 `base.z00` 时，`base.zip` 不得被赋予重复编号 1。

- [ ] **任务 0.3：解耦 `PostProcessRequest` 中的语义过载**
  - **位置**：`Core/Services/PostProcessService.cs`
  - **缺陷**：在 `Delete` 模式中借用布尔值 `PreflightWholeGroup` 作为判断压缩还是解压的词条分支开关。
  - **修复要求**：定义显式枚举 `PostProcessItemKind { CompressionSource, DecompressionArchive }`，在 `PostProcessRequest` 中传入，解耦词条分支与预检逻辑。

- [ ] **任务 0.4：补齐双循环表征测试护栏**
  - **位置**：`BatchCompress.Avalonia.Tests/Program.cs`
  - **新增测试用例**：
    1. **双循环取消传播**：验证在 `BatchCompressAsync` 和 `BatchDecompressAsync` 运行中通过 `CancellationToken` 取消时，抛出 `OperationCanceledException`、**绝不触发关机**、且压缩的 `stagingDirectory`（附件暂存目录）在 `finally` 中被可靠删除；
    2. **`ExistingFileMode.Update` 透传**：验证输出文件已存在时，服务层既不提前删除也不跳过，原样将 `Update` 选项透传给底层引擎（7z 传 `-aou` 等）；
    3. **预检失败状态断言**：锁定项目在不存在（`ItemNotFound`）或不完整分卷（`IncompleteVolumes`）跳过时，`progressInfo.CurrentFile` 的保留或刷新契约。

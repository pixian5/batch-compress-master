## 2. 后续推进建议

建议在后续小版本演进中聚焦：
1. **GUI 诊断导出快捷入口**：
   在 GUI 工具栏或关于页放置一键导出按钮，调用 `DiagnosticsExportService` 将脱敏诊断包直接生成至桌面并弹出通知；
2. **长任务子进度 UI 渲染**：
   在界面底部进度条中，结合 `SubProgressPercent` 提供“条目进度 + 批次总进度”双条展示体验。

## 1. 交付目标与背景

在批次 13 解决了在途残片回滚与数据损坏隐患后，本批次依据 Claude-Opus 深度分析报告中的 P0/P1/P2 高优先级改进项，重点强化工程发布可用性、持续集成严密性与多语言帮助完整性：
1. **构建与环境一致性**：锁定 .NET 10 SDK，防止云端 CI/Release 与开发者本地环境出现版本漂移；

4. **CLI 多语言帮助补全与结构解耦**：将帮助文本从 1,300 行的 `CommandLineHandler.cs` 解耦拆分至 `CommandLineHandler.HelpTexts.cs`，实现日文（`ja`）与德文（`de`，严格 0 中文字符）完整帮助文本，修复终端假名显示宽度计算。

## 2. 核心改动清单

### 2.1 锁定 SDK 与可重现工作流（P1-5）
- 新建根目录 `global.json`：
  ```json
  {
    "sdk": {
      "version": "10.0.403",
      "rollForward": "latestFeature"
    }
  }
  ```
- 修改 `.github/workflows/ci.yml` 与 `.github/workflows/release.yml`：
  将 `actions/setup-dotnet@v4` 的 `dotnet-version: '10.0.x'` 全面替换为 `global-json-file: global.json`，确保构建和发布流水线严格在基准 SDK 上执行。

### 2.2 发布校验和清单与产物安全扫描（P0-2）
- 修改 `.github/workflows/release.yml`：
  - 新增 `生成 SHA-256 校验和清单` 步骤：在 `.artifacts/release` 内执行 `sha256sum BatchCompress.Avalonia_* > SHA256SUMS.txt`，随同归档附件一并上传至 GitHub Releases；
  - 新增 `发布产物安全扫描（防日志/临时文件混入）` 步骤：在上传前解包检查 `.tar.gz` 与 `.zip` 归档，若出现 `*.log`、`*.tmp`、`enclosures.txt` 等临时或敏感文件，工作流强制阻断失败；
  - `README.md` 增加官方校验命令指引（Linux `sha256sum -c` / macOS `shasum -a 256 -c`）。

### 2.3 本地测试资产深度接入持续集成（P1-6）
- 修改 `scripts/package-all.sh`：
  `--check` 自检在非 Darwin 宿主上自动跳过仅限 macOS 的 `swiftc` 检查，使得跨平台 CI runner 可直接执行冒烟自检。
- 修改 `.github/workflows/ci.yml` 与 `release.yml`：
  - 在三平台 `build-test` / `test-gate` 作业中引入 `bash scripts/smoke-test.sh`；
  - 在 `macos-latest` 作业中引入 `zsh 测试夹具/经验验证/verify.sh`（16 项实测用例覆盖真实归档往返、权限、Ctrl+C 残片清理等）。

### 2.4 macOS 签名强化与硬化运行时（P0-1）
- 新建 `macos/entitlements.plist`：配置 `.NET` 运行时必须的 Hardened Runtime 权限（`allow-jit`、`allow-unsigned-executable-memory`、`disable-library-validation`）；
- 修改 `scripts/package-macos.sh`：
  - 检测 `APPLE_SIGNING_IDENTITY` 环境变量；若配置则启用 `--options runtime --entitlements ... --sign ...` 执行正式硬化运行时签名与 `--strict` 校验；
  - 若未配置证书，安全回退至 ad-hoc 签名（`-`），并输出清晰的 Gatekeeper 隔离属性绕过提示（`xattr -d com.apple.quarantine`）。

### 2.5 Linux `--no-rar` 开源纯净版打包选项（P0-3）
- 修改 `scripts/package-linux.sh`：
  - 增加 `--no-rar` 参数支持；
  - 启用后输出 `BatchCompress.Avalonia_<版本>_linux-x64-no-rar.tar.gz` 并自动剔除 `tools/rarLinux` 分发包；
  - 在 `docs/20260929-2351-RAR二进制许可风险说明-未标注.md` 中记录该方案，为有强合规诉求的用户提供纯开源发行通道。

### 2.6 CLI 日文与德文帮助补齐及大文件拆分（P2-8 & P2-9）
- **大文件拆分**：新建 `CommandLineHandler.HelpTexts.cs`（`partial class CommandLineHandler`），将 250 行的多语言常量移入，`CommandLineHandler.cs` 从 1,299 行直降至 1,051 行；
- **日文帮助（ja）**：实现 `JapaneseHelpText`，术语与 `LocalizationService` 严格对齐（`ヘッドレスバッチ圧縮を実行`、`バッチ処理ソースディレクトリ`、`ソリッド圧縮`等）；
- **德文帮助（de）**：实现 `GermanHelpText`，德语术语对齐且**严格 0 中文字符**；
- **日文假名终端宽度计算**：修改 `GetDisplayWidth` 与 `TokenizeForWrapping`，Unicode 宽字符判定范围扩展至 `0x3000 <= c && c <= 0x30ff`，全面涵盖平假名与片假名，防止终端折行计算失真；
- **测试工程同步扩展**：
  - 在 `BatchCompress.Avalonia.Tests/Program.cs` 升级 `TestCliHelpTextWrapping`，覆盖 4 语言折行与德语零中文断言；
  - 新增 `TestAllHelpTextsContainAllOptions` 测试，遍历 5 种语言帮助文本，严格断言全部 43 项 CLI 选项名均完整存在；
  - 控制台测试套件由 62 项扩充至 **63 项**全绿。

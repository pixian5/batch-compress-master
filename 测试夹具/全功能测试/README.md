# 全功能测试夹具

本目录用于覆盖 BatchCompress.Avalonia 的 CLI、归档引擎、解压扫描、密码本、附件、后处理和异常路径。

## 固定输入

- `来源目录/`：普通文本、空文件、中文、空格、特殊字符、嵌套目录和系统元数据样本。
- `附件/`：存在目录、空目录和清单中不存在的目录。
- `压缩路径清单.txt`：压缩模式一行一个路径，含重复项、相对路径和缺失项。
- `密码本.txt`：解压模式文件名/密码交替清单，含无后缀、大小写、分卷、重复和缺失项。
- `重复路径清单.txt`：用于验证 CLI 输入去重；GUI 文本列表重复项另行记录为已知检查项。
- `password.txt`、`comment.txt`：自定义密码和 RAR 注释输入。

## 运行约定

所有输出放在 `输出/`，临时目录放在 `临时/`，可用以下命令清理后重跑：

```bash
rm -rf '测试夹具/全功能测试/输出' '测试夹具/全功能测试/临时' '测试夹具/全功能测试/生成物'
mkdir -p '测试夹具/全功能测试/输出' '测试夹具/全功能测试/临时' '测试夹具/全功能测试/生成物'
```

测试报告中的命令以仓库根目录为当前目录，路径均使用引号包裹，以覆盖空格和中文路径。

## 一键实测

完成 Debug 构建后运行：

```bash
测试夹具/全功能测试/run-all-tests.sh
```

脚本会把上一次的 `输出/`、`临时/`、`生成物/` 移到 `/tmp` 备份，再重新创建全部输入和输出，最后打印每项退出码与文件校验结果。当前版本实测为 120 项通过；RAR、7z、ZIP、TAR、GZIP、BZIP2、XZ、WIM 的单卷/分卷能力均有实际检查，7z/ZIP 分卷开启 `--test` 已使用首卷校验并通过。

## 主要差异/缺失点（重点：跨平台细节）

### 高优先级（会导致“与旧版行为不一致”或“跨平台实际不可用”）

- **[分卷随机密码算法不一致]**（重要）  
  - 文档：分卷解压随机密码应基于 **`baseName + extension`（例如 `a.rar`）**，而不是第一卷文件名 `a.part001.rar`。  
  - 现状：[BatchOperationService.BatchDecompressAsync()](cci:1://file:///Users/x/code/trae/compress/BatchCompress.Avalonia/Core/Services/BatchOperationService.cs:384:4-526:5) 在无密码且启用随机密码时：  
    - [password = PasswordUtility.GenerateDecompressionPassword(archiveName)](cci:1://file:///Users/x/code/trae/compress/BatchCompress.Avalonia/Core/Services/PasswordUtility.cs:84:4-91:5)  
    - `archiveName` 对分卷是 `a.part001.rar`，**会生成与文档/旧版不一致的密码**。
- **[高级功能“解锁口令”算法不一致]**（有意取消）
  - 文档：高级解锁口令是 DayOfYear 的动态口令（旧版具体盐值规则在原 WinForms 里是固定的）。  
  - 现状：[PasswordUtility.GenerateUnlockPassword()](cci:1://file:///Users/x/code/trae/compress/BatchCompress.Avalonia/Core/Services/PasswordUtility.cs:93:4-102:5) 使用 [MD5UTF878(dayOfYear + "unlock")](cci:1://file:///Users/x/code/trae/compress/BatchCompress.Avalonia/Core/Services/PasswordUtility.cs:12:4-29:5)  
  - 旧版（你原项目）实际是：[MD5UTF874(DayOfYear + "我爱") + MD5UTF874(DayOfYear + "胖田田")](cci:1://file:///Users/x/code/trae/compress/BatchCompress.Avalonia/Core/Services/PasswordUtility.cs:31:4-48:5)  
  - 当前版本已移除许可证和动态解锁口令，所有高级选项默认可用；这不是迁移缺失。
- **[Linux/macOS 上“rar/unrar 发现”可能导致压缩不可用]**（跨平台落地关键点）  
  - 现状：`RarArchiveEngine.FindRarOnLinux/MacOS()` 会在 `PATH` 里依次找 `rar`、找不到再找 `unrar`。   
  - 文档期望：只使用rar。

### 中优先级（功能缺失/体验不一致）

- **[托盘/气泡通知/进度信息]**（已补齐）
  - 文档：NotifyIcon 托盘、气泡提示（含速度、剩余大小等）。  
  - 托盘支持显示/隐藏和退出；完成、取消及后台阶段进度通过跨平台系统通知报告，通知按里程碑节流。

- **[关机流程缺失“可取消交互” + 跨平台权限问题未处理]**  
  - 文档：完成后关机并弹窗允许取消。  
  - 现状：  
    - [BatchOperationService](cci:2://file:///Users/x/code/trae/compress/BatchCompress.Avalonia/Core/Services/BatchOperationService.cs:15:0-564:1) 结束后直接 [ShutdownAsync()](cci:1://file:///Users/x/code/trae/compress/BatchCompress.Avalonia/Core/Services/SystemIntegrationService.cs:91:4-112:5)

    - Linux/macOS 的 `shutdown -h +1` 通常需要 root 权限，当前实现不会提权/提示，失败会被吞掉。

- **[高级功能解锁后开放项不完整]**  
  - 已改为全部默认开放，不再存在解锁后范围不完整的问题。
  
- **[7z 输入处理方式不同]**  
  - 文档：输入 `7z` 时弹窗强制用户在 `rar/zip` 之间选。  
  - 现状：仅写日志 warning，不会强制修正。  

### 低优先级（UI/交互层面差异）

## 跨平台实现的落地细节（你最关心的部分）

- **[外部压缩器发现策略]**：[RarArchiveEngine](cci:2://file:///Users/x/code/trae/compress/BatchCompress.Avalonia/Core/Services/RarArchiveEngine.cs:14:0-420:1)

  - 使用 `ProcessStartInfo` + 参数里对路径加引号；并带 `-SCf`（UTF-8 文件名）来降低中文乱码风险，符合文档目标。

- **[系统集成]**：  
  - 打开目录：Windows `explorer.exe` / Linux `xdg-open` / macOS `open`（实现正确）

  - 通知/托盘：Windows、macOS、Linux 均有平台适配；通知权限和桌面环境能力仍由系统决定。

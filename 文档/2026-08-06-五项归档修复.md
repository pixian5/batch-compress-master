# 五项归档修复

GPT-5，2026-08-06：本轮修复记录。

## 行为

- 附件路径存在时，作为独立输入传给 RAR/7zz，因此以附件 basename 出现在归档根目录；不存在时只在临时暂存目录创建同名空目录，压缩完成或取消后清理暂存目录，不修改源目录。
- “锁定归档”改为显式选项。RAR 仅在启用该选项时传递 `-k`；`--existing update` 与锁定组合在 GUI 和 CLI 都会提示/拒绝。
- 已存在输出选择 skip 时增加 `IgnoreCount` 并报告进度；命令行仅有跳过项时返回码为 0，存在失败项仍返回 1。
- ZIP 和 7z 都由官方 7zz 处理，RAR 由 RAR 处理。所有参数通过 `ArgumentList` 逐项传递，stdout/stderr 同时异步读取。

## 工具

- `tools/rarmacOS/rar`、`unrar` 为 macOS arm64 官方 RAR 7.23。
- `tools/7zip/macos/7zz` 为官方 7-Zip 26.02 universal 二进制。
- `tools/rarmacOS/rarreg.key` 按项目约定保留，不写入 `.gitignore`。

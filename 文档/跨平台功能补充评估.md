# 跨平台功能补充评估

## 适合优先补充

- 恢复记录百分比设置，并绑定到 WinRAR 参数构建器。该功能只涉及业务参数，Windows、macOS、Linux 行为一致。
- 为附件目录提供 Avalonia 文件夹选择器，避免手动输入路径。路径选择使用 `StorageProvider`，不依赖平台专属 API。
- 恢复旧密码查询算法的兼容输出，继续使用当前跨平台的编码与哈希实现。
- 增加独立的源列表、成功日志、失败日志和命令日志清空命令。
- 增加 Avalonia 快捷键和帮助/Tooltip，属于纯 UI 层功能。

## 需要平台适配层

- 托盘图标、隐藏窗口和托盘恢复：Avalonia 主窗口本身跨平台，但系统托盘需要按 macOS、Windows、Linux 分别适配，不能直接移植 WinForms `NotifyIcon`。
- 系统通知：保留当前 `ISystemIntegration.ShowNotification` 接口，平台实现应使用原生通知机制，避免拼接 PowerShell 或 shell 命令。
- 完成后关机和取消关机：保留接口，但需要权限检查、失败反馈和平台实现；macOS/Linux 不应假定无需授权即可执行。

## 不建议直接恢复

- 7-Zip 和 WinRAR 混用。当前项目按要求统一使用 WinRAR，格式支持应继续由 WinRAR 能力决定。
- WinForms 控件、注册表查找和 `NotifyIcon` 代码。这些实现绑定 Windows，应迁移行为而不是迁移代码。

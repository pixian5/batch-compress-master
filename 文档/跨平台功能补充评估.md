# 跨平台功能补充评估

## 适合优先补充

- 恢复记录百分比设置，并绑定到 WinRAR 参数构建器。该功能只涉及业务参数，Windows、macOS、Linux 行为一致。
- 为附件目录提供 Avalonia 文件夹选择器，避免手动输入路径。路径选择使用 `StorageProvider`，不依赖平台专属 API。
- 恢复旧密码查询算法的兼容输出，继续使用当前跨平台的编码与哈希实现。
- 增加独立的源列表、成功日志、失败日志和命令日志清空命令。
- 增加 Avalonia 快捷键和帮助/Tooltip，属于纯 UI 层功能。

## 需要平台适配层

- 托盘图标、隐藏窗口和托盘恢复：Avalonia 主窗口本身跨平台，但系统托盘需要按 macOS、Windows、Linux 分别适配，不能直接移植 WinForms `NotifyIcon`。
- 系统通知：保留当前 `ISystemIntegration.ShowNotification` 接口，平台实现应使用原生通知机制，避免拼接 PowerShell 或 shell 命令。
- 完成后关机和取消关机：保留接口，但需要权限检查、失败反馈和平台实现；macOS/Linux 不应假定无需授权即可执行。

## 不建议直接恢复

- 7-Zip 和 WinRAR 混用。当前项目按要求统一使用 WinRAR，格式支持应继续由 WinRAR 能力决定。
- WinForms 控件、注册表查找和 `NotifyIcon` 代码。这些实现绑定 Windows，应迁移行为而不是迁移代码。

## 本轮落地（0.0.4）

- 恢复记录百分比已接入界面、批处理选项和 WinRAR `-rr` 参数，输入范围限制为 0 到 100。
- 附件目录改用 Avalonia `StorageProvider` 文件夹选择器，支持一次选择多个目录并合并到列表。
- 密码查询保留旧 WinForms 的候选算法，同时不改变当前最终复制密码。
- 源列表、成功日志、失败日志和命令日志现在可以分别清空，也保留一键清空全部日志。
- 增加 F5 刷新、Escape 取消、Ctrl+L 清空日志、Ctrl+H 隐藏到托盘，以及帮助窗口和 Tooltip。
- 使用 Avalonia 内置 `TrayIcon` 完成 Windows、macOS、Linux 的显示/隐藏、恢复和退出入口；关闭主窗口默认隐藏到托盘。
- 系统通知和文件管理器打开统一使用 `ProcessStartInfo.ArgumentList`。macOS 使用 `osascript`，Windows 使用 PowerShell 参数，Linux 使用 `notify-send`。
- 完成后关机和取消关机继续按系统命令执行，并在命令不可用、返回失败或权限不足时发送失败通知。

## 平台边界

- 托盘是否显示取决于桌面环境：Linux 无桌面托盘扩展时可能没有托盘图标，但主窗口功能仍可用。
- 系统关机通常需要管理员权限：Windows 可能受组策略限制，macOS/Linux 可能要求授权或 polkit。应用不会绕过系统权限。
- WinRAR 仍是唯一压缩引擎；用户需要在各平台安装可执行的 `rar`/`winrar` 并配置到现有查找路径。

## macOS 安装

- 使用 `scripts/package-macos.sh` 从 `Assets/压缩.ico` 生成 Avalonia PNG 和 Finder 使用的 `macos/压缩.icns`。
- 脚本发布 Apple Silicon 自包含版本，创建并签名 `/Applications/BatchCompress.Avalonia.app`。
- 不要直接通过 `dotnet run` 作为最终桌面应用启动；直接运行缺少 macOS 应用包元数据，可能造成 Finder 图标空白或后台进程无法关联窗口。

## 窗口与提示

- 顶栏关闭现在会真正退出应用；需要后台运行时使用“隐藏到托盘”按钮，再从托盘菜单显示或退出。
- 窗口大小、位置和最大化状态写入当前用户的应用数据目录：Windows 使用 `%AppData%`，macOS 使用 `~/Library/Application Support`，Linux 使用桌面环境提供的应用数据目录。不要写入应用包目录，以免更新后丢失配置或破坏签名。
- Tooltip 使用统一黄色样式，并覆盖路径、密码、压缩参数、后处理和主要操作按钮。

## 功能可用性

- 已移除高级功能的每日密码验证。自定义格式、分卷、注释、附件和完成后关机等选项默认可用，不再保留解锁状态、命令或口令算法。

## 代码维护

- 已清理当前源码中的乱码注释；入口、命令行、批处理、WinRAR、系统集成、窗口、ViewModel、本地化、测试、XAML、项目配置和打包脚本均补充了带 `GPT-5, 2026-08-05` 标记的维护注释。
- macOS Finder/LaunchServices 传入的 `-psn_*` 进程序列参数会在程序入口过滤，确保从 `/Applications` 双击启动不会被命令行解析器误判为未知选项。
- `SystemMetadataFileFilter` 会在枚举、TXT 导入、手工列表和执行前统一跳过 Windows、macOS、Linux 的系统元数据及常见锁文件，例如 `desktop.ini`、`Thumbs.db`、`.DS_Store`、AppleDouble、Spotlight、Trash、`.directory`、`.gvfs`、`lost+found` 和 `~$` 文件。
- WinRAR 的原始 stdout/stderr 现在不再替换密码，进程输出会完整保留用于诊断；代码明确禁止对进程输出执行脱敏、替换或掩码，命令参数记录维持原有策略。

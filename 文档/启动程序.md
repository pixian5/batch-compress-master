# 启动程序

## 问题描述
启动 Avalonia 跨平台批量压缩解压工具程序。

## 执行内容

### 启动命令
```bash
dotnet run --project BatchCompress.Avalonia.csproj --no-launch-profile
```

### 运行状态
- ✅ 程序成功启动
- ✅ 应用程序正在运行中
- ⚠️ 有一个警告（不影响运行）

### 警告信息
```
/Users/x/code/trae/compress/Core/Services/SystemIntegrationService.cs(54,34): warning CS0618: 'IClipboard.GetTextAsync()' is obsolete: 'Use ClipboardExtensions.TryGetTextAsync instead'
```

**说明**: 这是一个编译时警告，提示使用了过时的剪贴板 API。虽然不影响程序运行，但建议后续修复。

## 验证内容

程序启动后，可以验证以下之前修改的功能：

1. **按钮位置交换**
   - 来源部分：[来源路径文本框] [选择来源按钮]
   - 目的地部分：[同上按钮] [选择目录按钮]

2. **默认值设置**
   - "注释"选项默认勾选
   - "分卷"选项默认勾选
   - 分卷大小默认为 20GB
   - GB 单位下拉列表宽度已增加

3. **UI 布局优化**
   - 压缩选项和后处理选项合并到同一列
   - 使用两列布局展示所有选项

## 程序功能

应用程序窗口标题：批量压缩解压工具 v<当前版本>

主要功能模块：
- 来源与目标选择
- 压缩选项配置
- 后处理选项配置
- 操作按钮（压缩、解压、中止等）
- 密码查询功能
- 日志查看（待处理文件列表、成功记录、失败记录、命令日志）

## 说明

Avalonia 是一个跨平台的 UI 框架，在 macOS 上运行时会打开原生窗口。由于是 GUI 应用程序，终端中不会显示太多输出信息，这是正常现象。

程序会持续运行，直到手动关闭窗口或终止进程。

# 快速参考指南

## 一分钟快速开始

### 压缩文件

1. 点击【从哪儿来】选择源文件夹
2. 点击【到哪儿去】选择目标文件夹
3. 勾选【随机密码】
4. 点击【压缩！】

### 解压文件

1. 在源路径输入压缩文件所在文件夹
2. 点击【选txt】选择包含文件名和密码的txt
3. 点击【到哪儿去】选择解压目标
4. 点击【解压！】

## 常用操作速查

### 压缩选项

| 功能 | 位置 | 说明 |
|------|------|------|
| 随机密码 | 复选框 | 每个文件独立密码 |
| 自定义密码 | 文本框 | 所有文件同一密码 |
| 压缩率 | 下拉框 | 0=不压缩，1=轻度，5=极限 |
| 固实 | 复选框 | 更高压缩率，但部分网盘不支持在线解压 |
| 分卷 | 复选框+文本框 | 拆分成多个文件 |
| 存在时 | 下拉框 | 跳过/更新/覆盖 |
| 压缩后删除 | 复选框 | 删除源文件（危险！） |
| 压缩后移动 | 复选框 | 移动到"已压缩"文件夹 |

### 快捷键

| 按键 | 功能 |
|------|------|
| F5 | 刷新文件列表 |

### WinRAR 错误码

| 代码 | 含义 | 处理方法 |
|------|------|----------|
| 0 | 成功 | - |
| 1 | 警告 | 通常可忽略 |
| 2 | 致命错误 | 检查文件和权限 |
| 3 | 数据损坏 | 文件可能损坏 |
| 4 | 文件锁定 | 关闭占用文件的程序 |
| 5 | 写入失败 | 检查磁盘空间和权限 |
| 11 | 密码错误 | 检查密码 |

## 常见任务

### 批量压缩文件夹

```
1. 选择"压缩此文件夹内所有文件"
2. 【从哪儿来】→ 选择包含待压缩文件的文件夹
3. 【到哪儿去】→ 选择保存压缩文件的位置
4. 配置:
   - 勾选【随机密码】
   - 【压缩率】选"轻度压缩"
   - 勾选【压缩后移动到"已压缩"】
5. 点击【压缩！】
```

### 从txt解压文件

```
准备txt文件（格式）:
文件1
密码1
文件2
密码2

步骤:
1. 选择"从此txt读取要压缩的文件"
2. 在源路径输入压缩文件所在文件夹
3. 点击【选txt】选择密码txt
4. 点击【到哪儿去】选择解压位置
5. 点击【解压！】
```

### 创建加密分卷压缩

```
1. 选择源文件
2. 勾选【随机密码】或输入自定义密码
3. 勾选【分卷】
4. 输入分卷大小（如"300"）
5. 选择单位（m = MB）
6. 点击【压缩！】

结果: 文件.part01.rar, 文件.part02.rar, ...
```

### 查询随机密码

```
1. 在文件名输入框输入文件名（不带扩展名）
2. 点击【查询密码】
3. 密码自动复制到剪贴板
4. 在命令历史框查看所有密码算法的结果
```

## 最佳实践

### 压缩速度优先

- 压缩率: 不压缩 或 轻度压缩
- 不勾选"固实"
- 临时文件夹: 设置在SSD上
- 不勾选"校验"

### 压缩率优先

- 压缩率: 极限压缩
- 勾选"固实"
- 不添加恢复记录（节省空间）

### 网盘上传

- 压缩率: 不压缩 或 轻度压缩
- **不勾选"固实"**（重要！部分网盘不支持在线解压固实文件）
- 不分卷（除非文件超过网盘单文件大小限制）

### 安全存储

- 勾选【随机密码】
- 添加恢复记录（3-5%）
- 勾选【校验】
- 保存密码到安全的地方

## 故障排除

### 压缩失败

**检查清单**:
- [ ] 是否安装 WinRAR 5.0+
- [ ] 源文件是否存在
- [ ] 目标文件夹是否有写入权限
- [ ] 磁盘空间是否足够
- [ ] 文件是否被其他程序占用

### 解压失败

**检查清单**:
- [ ] 压缩文件是否完整（检查文件大小）
- [ ] 密码是否正确
- [ ] 如果是分卷，是否所有分卷都存在
- [ ] 目标文件夹是否有写入权限
- [ ] 磁盘空间是否足够

### UI无响应

**原因**: 可能在处理大量文件

**解决**:
- 等待当前文件处理完成
- 点击【取消】中断操作
- 查看系统托盘的进度提示

### 程序无法启动

**常见原因**:
1. 缺少 .NET 8.0 运行时
   - 下载: https://dotnet.microsoft.com/download/dotnet/8.0
2. 缺少管理员权限
   - 右键程序 → 以管理员身份运行

## 技巧和窍门

### 1. 剪贴板集成

程序启动时自动读取剪贴板中的文件夹路径，方便快速选择。

```
在资源管理器复制文件夹路径 → 启动程序 → 自动填充
```

### 2. 拖放支持

可以将文件夹直接拖到源路径文本框。

### 3. 自动刷新

源路径改变时自动刷新文件列表。

### 4. 批量查询密码

在命令历史框可以看到多种密码算法的结果，方便尝试解压旧文件。

### 5. 系统托盘

- 单击: 无操作
- 双击: 显示/隐藏主窗口
- 气泡提示: 显示实时进度

### 6. 进度监控

查看方式:
1. 主窗口进度显示
2. 系统托盘图标提示
3. 日志输出框
4. Windows任务栏进度条（某些版本）

### 7. 批处理脚本

创建批处理脚本自动化操作:

```batch
@echo off
:: 启动程序并等待完成
start /wait "批量压缩" "批量压缩与解压.exe"
:: 处理完成后的操作
echo 压缩完成
pause
```

## 性能数据参考

### 压缩速度（参考）

| 压缩率 | 固实 | 速度 | 压缩比 |
|--------|------|------|--------|
| 不压缩 | 否 | ~100MB/s | 1:1 |
| 轻度压缩 | 否 | ~50MB/s | 1.5:1 |
| 轻度压缩 | 是 | ~40MB/s | 2:1 |
| 极限压缩 | 是 | ~5MB/s | 3:1 |

*注: 实际速度取决于CPU、硬盘速度和文件类型*

### 磁盘空间需求

压缩时临时空间 ≈ 源文件大小

建议剩余空间: 源文件大小的 1.5 倍

## 命令行参考

### WinRAR 常用参数

```
A      - 添加文件到压缩包
x      - 解压保留路径
e      - 解压不保留路径
-p     - 设置密码
-m0    - 不压缩
-m1    - 轻度压缩
-m5    - 极限压缩
-s     - 固实压缩
-v     - 分卷大小
-k     - 锁定压缩包
-rr    - 恢复记录
-o+    - 覆盖已存在文件
-o-    - 跳过已存在文件
```

### 手动执行压缩

```cmd
rar a -p"密码" /path/to/output.rar /path/to/input.txt
```

### 手动执行解压

```cmd
rar x -p"密码" /path/to/input.rar /path/to/output/
```

## 文件格式

### txt 密码文件格式

```
文件1
密码1
文件2
密码2
...
```

**规则**:
- 奇数行: 文件名（不含路径和扩展名）
- 偶数行: 对应密码
- 不要有空行
- 使用UTF-8编码

### 分卷文件命名

```
文件.part001.rar
文件.part002.rar
文件.part003.rar
...
```

或

```
文件.part01.rar
文件.part02.rar
文件.part03.rar
...
```

**注意**: 只需解压第一卷，其他卷会自动使用

## 限制和注意事项

### 系统要求

- 操作系统: Windows 7/8/10/11
- .NET: 8.0 Runtime
- WinRAR: 5.0 或更高
- 权限: 管理员权限

### 文件大小

- 单文件: 无限制（受WinRAR限制）
- 总大小: 无限制（受磁盘空间限制）
- 推荐: 单次处理 < 500GB

### 并发

- 每次只能运行一个压缩/解压任务
- 可同时运行多个程序实例

### 路径长度

Windows 路径长度限制: 260 字符
如果路径过长，可能导致操作失败

**解决方法**:
- 使用较短的路径
- 启用Windows长路径支持（需修改注册表）

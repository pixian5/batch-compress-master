# 快速参考

> 状态：2026-11-05 复核到 `VERSION 0.7.6`。完整参数见 [命令行参考](COMMAND_LINE.md)，
> 避坑速查见 [经验索引](../经验/README.md)，可复跑实测见 `测试夹具/经验验证/verify.sh`。

## 批量压缩

1. 选择来源：目录、TXT 文件或拖入文件。
2. 选择保存目录；为空时操作会被阻止并提示。
3. 设置创建格式为 `rar`、`7z`、`zip`、`tar`、`gz`、`bz2`、`xz` 或 `wim`，再按需设置密码、分卷、校验和后处理。
4. 运行压缩，进度和原始归档程序输出显示在日志页。恢复记录、快速打开、锁定和注释只适用于 RAR。

## 批量解压

选择来源和输出目录后运行解压。随机密码、输入密码和 TXT 中的逐项密码均可使用。
对于历史归档，可用密码查询生成当前和旧版候选密码（MD5 派生只为兼容旧密码，不是密码学保护）。

## 托盘与窗口

- 选择「隐藏到托盘」仅隐藏窗口；普通关闭窗口会退出应用。
- 点击托盘图标或「显示/隐藏」菜单可切换主窗口。
- macOS 菜单栏显示「压」图标，由随应用包分发的**原生状态栏帮助进程**提供
  （Avalonia 自带托盘在该平台不生成状态栏项）；切换界面语言时会重启它以刷新菜单文案。
- 不要用 `open -n` 启动 macOS 应用，会在 Dock 最近使用留下重复记录。

## 命令行

- `compress` 创建归档，`extract` 解压；旧 `--compress`、`--decompress` 继续兼容。
- `--source` 表示批处理目录，`--input` 表示精确项目并可重复，`--text-file` 用于解压密码清单。
- `--language/--lang` 支持五语言；只传语言且不带批处理参数时以该语言启动图形界面。
- `--concurrency N` / `-j N` 设置并发度 1-16，默认 1 串行；并发下完成顺序不保证等于输入顺序。
- `--password-file` 或 `--password-stdin` 可避免把密码直接写在本工具的命令行中；
  但 RAR/7zz 子进程参数和原始日志仍会保留密码。
- `--dry-run` 只列出任务，不创建输出目录或归档；`--verbose` 显示完整归档程序输出；`--quiet` 只输出错误。
- `--output-format json` 输出逐行 JSON 事件流（NDJSON，Newline Delimited JSON），适用于脚本消费。
- 退出码：`0` 成功 / `1` 任务失败 / `2` 参数错误 / `130` Ctrl+C 取消。

### 实测边界（容易踩）

`--dry-run` 会提前返回，**即使加了 `--output-format json` 也不产生事件流**：
标准输出为空，DRY-RUN 清单写在标准错误。自动化脚本联调 NDJSON 时必须用真实执行。

## 常见问题

- 找不到 RAR：安装完整 RAR/WinRAR，而非仅 `unrar`，或设置 `BATCHCOMPRESS_RAR_PATH` 指向已获授权的 `rar`；这只影响 RAR，其它格式仍可用项目内官方 `7zz`（当前 26.05）。
- 找不到 7-Zip：检查应用或输出目录中的 `tools/7zip/<平台>/7zz`；macOS 应用内路径为 `Contents/MacOS/tools/7zip/macos/7zz`。从访达启动时系统 `PATH` 不可靠，所以用固定相对路径。
- 来源路径带尾部斜杠：收集阶段会统一规范化，不会生成 `.7z` 空名归档。
- 7z 的「更新」解压策略：7-Zip 没有与 WinRAR 完全相同的更新开关，当前映射为自动重命名新解压文件，避免覆盖已有文件。
- 关机失败：系统拒绝了关机命令或权限不足，任务结果不会因此回滚。
- 日志显示密码：命令输出刻意保留原文用于诊断，请在共享日志前自行检查；日志权限 0600，第 1 代纯文本、第 2 代起 Gzip 压缩。

# 同上按钮右侧应该和上方下拉列表右侧对齐

## 问题
用户要求"同上"按钮的右侧应该和上方下拉列表的右侧对齐。

## 解决方案
在 MainWindow.axaml 中使用嵌套Grid容器实现精确对齐：

### 修改内容
目的地部分使用独立的Grid容器，定义5列布局：
- 第0列：宽度200（与上方下拉列表所在列相同）
- 第1列：宽度60（用于"同上"按钮）
- 第2列：宽度400（用于输出路径文本框）
- 第3列：宽度100（用于"选择目录"按钮）
- 第4列：Auto（用于输出大小文本）

### 关键实现
```xml
<!-- Output Path -->
<Grid Grid.Row="2" Grid.Column="0" Grid.ColumnSpan="5" ColumnDefinitions="200,60,400,100,Auto">
    <TextBlock Grid.Column="0" Text="目的地：" VerticalAlignment="Center"/>
    <Button Grid.Column="0" Content="同上" Command="{Binding SetOutputSameAsSourceCommand}" 
            HorizontalAlignment="Right" Width="60" VerticalAlignment="Center"/>
    <TextBox Grid.Column="2" Text="{Binding OutputPath}" VerticalAlignment="Center"/>
    <Button Grid.Column="3" Content="选择目录" Command="{Binding BrowseOutputCommand}" VerticalAlignment="Center"/>
    <TextBlock Grid.Column="4" Text="{Binding OutputSizeText}" VerticalAlignment="Center" Foreground="Blue"/>
</Grid>
```

### 对齐原理
1. "同上"按钮放置在第0列（宽度200）
2. 使用 `HorizontalAlignment="Right"` 使按钮右对齐
3. 设置 `Width="60"` 固定按钮宽度
4. 由于第0列宽度为200，按钮右对齐后，其右侧会与列的右侧（即上方下拉列表的右侧）对齐

### 效果
- "同上"按钮的右侧与上方下拉列表的右侧完美对齐
- "选择目录"按钮与"选择来源"按钮水平对齐
- 左侧两个文本框（来源路径和输出路径）水平对齐
- 整体布局更加整洁美观

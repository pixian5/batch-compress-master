# 压缩选项包括附加选项和后处理选项

## 问题分析

用户要求将压缩选项、附件选项和后处理选项整合在一起，使它们都包含在压缩选项的范围内。

## 解决方案

在 MainWindow.axaml 中进行了以下修改：

### 1. 布局结构整合

**修改Grid列定义**：
```xml
<!-- 修改前 -->
<Grid ColumnDefinitions="*,*,*" ColumnSpacing="10">

<!-- 修改后 -->
<Grid ColumnDefinitions="*">
```

### 2. 压缩选项Expander扩展

**将所有选项整合到压缩选项的Expander中**：
```xml
<Expander Grid.Column="0" Header="压缩选项" FontWeight="Bold" FontSize="14" IsExpanded="False">
    <StackPanel Spacing="15">
        <!-- 原始压缩选项Grid -->
        <Grid ColumnDefinitions="Auto,*,Auto,*" RowDefinitions="Auto,Auto,Auto,Auto,Auto,Auto" Margin="0,5">
            <!-- 所有原始压缩选项 -->
        </Grid>
        
        <!-- 附件目录列表 -->
        <StackPanel IsVisible="{Binding AddEnclosures}" Margin="0,5">
            <TextBlock Text="附件目录列表（每行一个）：" Margin="0,5,0,5"/>
            <TextBox Text="{Binding EnclosureList}" Height="80" AcceptsReturn="True" TextWrapping="Wrap"
                     IsEnabled="{Binding AddEnclosures}"/>
        </StackPanel>
        
        <!-- 后处理选项 -->
        <Border BorderBrush="LightGray" BorderThickness="1" Padding="10" CornerRadius="5">
            <StackPanel Spacing="8">
                <TextBlock Text="后处理选项" FontWeight="Bold" FontSize="14"/>
                <!-- 所有后处理选项 -->
            </StackPanel>
        </Border>
    </StackPanel>
</Expander>
```

### 3. 添加附件作为直接子项

**将添加附件功能整合到压缩选项Grid中**：
```xml
<!-- 修改前 -->
<Grid ColumnDefinitions="Auto,*,Auto,*" RowDefinitions="Auto,Auto,Auto,Auto,Auto" Margin="0,5">

<!-- 修改后 -->
<Grid ColumnDefinitions="Auto,*,Auto,*" RowDefinitions="Auto,Auto,Auto,Auto,Auto,Auto" Margin="0,5">
    
    <!-- 新增第5行：添加附件 -->
    <CheckBox Grid.Row="5" Grid.Column="0" Content="添加附件" IsChecked="{Binding AddEnclosures}" Margin="0,0,10,5"/>
</Grid>
```

### 4. 移除不必要的边框

**将附件目录列表作为独立元素**：
```xml
<!-- 移除了附件选项的边框容器 -->
<StackPanel IsVisible="{Binding AddEnclosures}" Margin="0,5">
    <TextBlock Text="附件目录列表（每行一个）：" Margin="0,5,0,5"/>
    <TextBox Text="{Binding EnclosureList}" Height="80" AcceptsReturn="True" TextWrapping="Wrap"
             IsEnabled="{Binding AddEnclosures}"/>
</StackPanel>
```

## 效果

- **统一的压缩选项面板**：所有与压缩相关的选项都包含在压缩选项Expander中
- **直观的布局**：添加附件是压缩选项的直接子项
- **条件显示**：只有勾选"添加附件"后才显示附件目录列表
- **视觉区分**：后处理选项仍保持独立的边框容器，便于区分

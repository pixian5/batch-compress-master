# 添加压缩和解压命令输出到日志功能

## 修改内容
为程序添加了将实际执行的压缩和解压命令输出到命令日志的功能。

## 具体修改

### 1. IArchiveEngine接口修改
在 `Core/Interfaces/IArchiveEngine.cs` 中添加了 `CurrentCommand` 属性：
```csharp
/// <summary>
/// Current command being executed
/// </summary>
string? CurrentCommand { get; }
```

### 2. RarArchiveEngine类修改
在 `Core/Services/RarArchiveEngine.cs` 中：
- 添加了 `CurrentCommand` 属性用于存储最后执行的命令
- 修改了 `BuildCompressionArguments` 和 `BuildExtractionArguments` 方法，在构建命令后保存完整的命令行到 `CurrentCommand` 属性

### 3. BatchOperationService类修改
在 `Core/Services/BatchOperationService.cs` 中：
- 在 `BatchCompressAsync` 方法中，执行压缩后输出命令日志
- 在 `BatchDecompressAsync` 方法中，执行解压后输出命令日志

## 输出示例

执行压缩或解压操作时，命令日志中会显示类似以下内容：

```
Command: rar a -ep1 -IBCK -SCf -o+ -p"password123" -m3 -s -md32 -k "/path/to/output/test.rar" "/path/to/input/test.txt"
Success: test.txt
```

## 技术实现

- **命令构建**：由 `RarArchiveEngine` 类负责构建完整的RAR命令行参数
- **命令记录**：通过 `CurrentCommand` 属性记录完整的命令行（包括RAR可执行文件路径和参数）
- **日志输出**：在 `BatchOperationService` 中执行操作后，将命令输出到进度报告中
- **UI显示**：命令日志通过绑定显示在界面的"命令日志"标签页中

# 交换选择目录和同上按钮位置

## 问题描述
将目的地部分的"选择目录"和"同上"按钮的位置进行交换。

## 修改内容

### 文件修改
- **文件路径**: [Views/MainWindow.axaml](file:///Users/x/code/trae/compress/Views/MainWindow.axaml)
- **修改位置**: 第43-49行

### 修改详情
将输出路径部分的按钮顺序从：
```
目的地：[选择目录] [文本框] [同上] [大小显示]
```
修改为：
```
目的地：[同上] [选择目录] [文本框] [大小显示]
```

### 代码变更
```xml
<!-- 修改前 -->
<StackPanel Orientation="Horizontal" Spacing="10">
    <TextBlock Text="目的地：" VerticalAlignment="Center" Width="100"/>
    <Button Content="选择目录" Command="{Binding BrowseOutputCommand}" Width="100"/>
    <TextBox Text="{Binding OutputPath}" Width="400"/>
    <Button Content="同上" Command="{Binding SetOutputSameAsSourceCommand}" Width="60"/>
    <TextBlock Text="{Binding OutputSizeText}" VerticalAlignment="Center" Foreground="Blue"/>
</StackPanel>

<!-- 修改后 -->
<StackPanel Orientation="Horizontal" Spacing="10">
    <TextBlock Text="目的地：" VerticalAlignment="Center" Width="100"/>
    <Button Content="同上" Command="{Binding SetOutputSameAsSourceCommand}" Width="60"/>
    <Button Content="选择目录" Command="{Binding BrowseOutputCommand}" Width="100"/>
    <TextBox Text="{Binding OutputPath}" Width="400"/>
    <TextBlock Text="{Binding OutputSizeText}" VerticalAlignment="Center" Foreground="Blue"/>
</StackPanel>
```

## 功能说明
- "同上"按钮：将输出路径设置为与源路径相同
- "选择目录"按钮：打开文件夹选择对话框让用户选择输出路径
- 按钮位置交换后，用户可以更方便地先点击"同上"快速设置输出路径，然后再根据需要点击"选择目录"进行修改

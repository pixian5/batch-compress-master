这3个项目右侧应该显示有多少个项目？

## 问题分析
用户希望在标签页标题中显示每个列表的项目数量，以便直观了解各列表中的内容数量。

## 修复过程
1. **添加计算属性**：在`MainWindowViewModel.cs`中添加了4个计算属性，用于生成包含项目数量的标签页标题：
   - `SourceFileListTabHeader`：显示待处理文件列表的项目数量
   - `SuccessLogTabHeader`：显示成功记录的项目数量
   - `FailLogTabHeader`：显示失败记录的项目数量
   - `CommandLogTabHeader`：显示命令日志的项目数量

2. **修改绑定**：在`MainWindow.axaml`中修改了`TabItem`的`Header`属性，将其绑定到新创建的计算属性

3. **添加通知属性变更**：在`SourceFileList`、`SuccessLog`、`FailLog`和`CommandLog`属性上添加了`[NotifyPropertyChangedFor]`装饰器，确保当这些属性变化时，对应的标签页标题也会更新

## 修复代码
**ViewModel部分**：
```csharp
// Tab header with item count
public string SourceFileListTabHeader => $"待处理文件列表 ({SourceFileList.Split(new[] { '\r', '\n' }, StringSplitOptions.RemoveEmptyEntries).Length})";
public string SuccessLogTabHeader => $"成功记录 ({SuccessLog.Split(new[] { '\r', '\n' }, StringSplitOptions.RemoveEmptyEntries).Length})";
public string FailLogTabHeader => $"失败记录 ({FailLog.Split(new[] { '\r', '\n' }, StringSplitOptions.RemoveEmptyEntries).Length})";
public string CommandLogTabHeader => $"命令日志 ({CommandLog.Split(new[] { '\r', '\n' }, StringSplitOptions.RemoveEmptyEntries).Length})";

// 添加通知属性变更装饰器
[ObservableProperty]
[NotifyPropertyChangedFor(nameof(SourceFileListTabHeader))]
private string _sourceFileList = string.Empty;

[ObservableProperty]
[NotifyPropertyChangedFor(nameof(SuccessLogTabHeader))]
private string _successLog = string.Empty;

[ObservableProperty]
[NotifyPropertyChangedFor(nameof(FailLogTabHeader))]
private string _failLog = string.Empty;

[ObservableProperty]
[NotifyPropertyChangedFor(nameof(CommandLogTabHeader))]
private string _commandLog = string.Empty;
```

**XAML部分**：
```xaml
<TabControl Height="300">
    <TabItem Header="{Binding SourceFileListTabHeader}">
        <ScrollViewer>
            <TextBox Text="{Binding SourceFileList}" AcceptsReturn="True" TextWrapping="Wrap" 
                     IsReadOnly="False" BorderThickness="0"/>
        </ScrollViewer>
    </TabItem>
    <TabItem Header="{Binding SuccessLogTabHeader}">
        <ScrollViewer>
            <TextBox Text="{Binding SuccessLog}" AcceptsReturn="True" TextWrapping="Wrap" 
                     IsReadOnly="True" BorderThickness="0" Foreground="Green"/>
        </ScrollViewer>
    </TabItem>
    <TabItem Header="{Binding FailLogTabHeader}">
        <ScrollViewer>
            <TextBox Text="{Binding FailLog}" AcceptsReturn="True" TextWrapping="Wrap" 
                     IsReadOnly="True" BorderThickness="0" Foreground="Red"/>
        </ScrollViewer>
    </TabItem>
    <TabItem Header="{Binding CommandLogTabHeader}">
        <ScrollViewer>
            <TextBox Text="{Binding CommandLog}" AcceptsReturn="True" TextWrapping="Wrap" 
                     IsReadOnly="True" BorderThickness="0"/>
        </ScrollViewer>
    </TabItem>
</TabControl>
```

## 验证结果
- 程序运行正常，无编译错误
- 标签页标题现在显示每个列表的项目数量，格式为："标题名称 (项目数量)"
- 当列表内容变化时，项目数量会自动更新

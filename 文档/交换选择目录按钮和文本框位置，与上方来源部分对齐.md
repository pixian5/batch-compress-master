# 交换选择目录按钮和文本框位置，与上方来源部分对齐

## 问题描述
将目的地部分的"选择目录"按钮和文本框交换位置，使其与上方的来源部分对齐。

## 修改内容

### 文件修改
- **文件路径**: [Views/MainWindow.axaml](file:///Users/x/code/trae/compress/Views/MainWindow.axaml)
- **修改位置**: 第44-50行

### 修改详情

**修改前的布局**:
```
来源部分：
[下拉框] [来源路径文本框] [选择来源按钮]

目的地部分：
[目的地标签] [同上按钮] [选择目录按钮] [文本框] [大小显示]
```

**修改后的布局**:
```

[下拉框] [来源路径文本框] [选择来源按钮]
```


## 对齐效果

修改后，目的地部分的控件顺序与来源部分保持一致：
- 文本框在前，按钮在后
- 用户可以先查看路径，再根据需要点击按钮进行修改
- 整体布局更加统一和美观

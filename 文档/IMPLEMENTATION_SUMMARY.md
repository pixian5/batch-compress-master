# 当前实现摘要

> 状态：2026-11-05 复核到 `VERSION 0.7.6`。本文只列已实现的能力与边界；
> 模块分层见 [当前架构](ARCHITECTURE.md)，逐项实现以源码为准。

当前代码已完成从旧 WinForms 业务规则到 Avalonia（图形界面框架）MVVM
（模型-视图-视图模型）的迁移，并保留以下兼容性与边界。

- **入口**：`Program.Main` 在初始化界面框架前处理帮助、版本与参数错误；图形界面与命令行共用
  同一套 `BatchOperationService` 与 `ArchiveEngineRouter`，能力一致。
- **来源**：目录扫描、手工列表、TXT 清单/密码本三种输入经 `SourceCollector` 统一规范化
  （去尾部斜杠、保序去重、过滤系统元数据）；分卷组折叠为单个任务入口。
- **密码**：保留随机密码派生和旧版候选密码查询；这些函数用于兼容历史归档，**不是密码学保护机制**。
- **归档**：RAR 使用 RAR/WinRAR，其余格式使用项目内官方 `7zz`（26.05）。
  按创建格式和待解压文件名选择后端；进程以 `ArgumentList` 逐项传参、异步并行收集输出，
  支持取消（杀整棵子进程树）与失败退出码处理。
- **执行管线**：`Core/Services/Pipeline/` 的通用管线负责循环、取消、计数、并发与关机；
  压缩/解压的条目级差异由两个适配器提供；`MaxConcurrency > 1` 时信号量限流、
  共享状态加锁并上报克隆快照；大小上限只拦未启动任务，关机只在正常结束时触发恰好一次。
- **后处理**：删除、移动、改名统一走 `PostProcessService`，归档成功与后处理成功分别计数。
- **输出**：支持 `--output-format json` 的 NDJSON（逐行 JSON）事件流，含密码的命令行整条排除；
  试运行模式不产生事件流（DRY-RUN 清单走标准错误）。
- **日志**：多代轮转（第 1 代纯文本、第 2 代起 Gzip 压缩）、权限 0600、保留天数可配；
  原始命令与进程输出**含明文密码且不脱敏**，属既定诊断行为，日志不可公开。
- **本地化**：五语言（简体中文、繁體中文、English、日本語、Deutsch）；
  界面与命令行共用同一套资源，切换语言时刷新托盘/状态栏文案。
- **界面**：原生文件夹选择器、拖放、快捷键、黄色 Tooltip、系统托盘与窗口状态记忆均已接入；
  macOS 托盘由随包 Swift 原生帮助进程提供。
- **附件**：联系方式由 `EnclosureConfigService` 三级路径解析，无配置回退默认模版，IO 失败不阻断启动。
- **系统**：打开目录、通知、关机与取消关机按 Windows/macOS/Linux 分支实现；权限受宿主系统控制。
- **授权**：已移除高级功能验证，所有可见选项均默认解锁。

# 当前实现摘要

当前代码已完成从 WinForms 业务规则到 Avalonia MVVM 的迁移，并在实际实现中保留以下兼容性与边界。

- 密码：保留随机密码派生和旧版候选密码查询；这些函数用于兼容历史归档，不是密码学保护机制。
- 归档：RAR 使用 RAR/WinRAR，ZIP/7z 使用项目内官方 7zz。路由按创建格式和待解压文件名选择后端；进程以独立参数启动，异步收集输出，支持取消和失败退出码处理。
- 批处理：目录、TXT、手工列表在执行前再次过滤系统元数据；进度、成功、失败、忽略和命令日志可分别清空。
- UI：原生文件夹选择器、拖放、快捷键、黄色 Tooltip、系统托盘与窗口状态记忆均已接入。
- 系统：目录打开、通知、关机与取消关机按 Windows/macOS/Linux 分支实现；权限受宿主系统控制。
- 授权：已移除高级功能验证，所有可见选项均默认解锁。

回归测试当前覆盖格式、密码参数、取消、失败返回码、恢复记录、旧密码、系统元数据过滤、完整命令行解析与错误校验。真实入口测试还覆盖 dry-run、带密码 7z 压缩、创建后校验、verbose 原始输出和解压内容一致性。

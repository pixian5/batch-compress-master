每行之间应该有一点行间距。

## 问题分析
用户希望在"来源与目标"区域的行之间增加行间距，使界面看起来更加清晰和美观。当前界面中，各控件行之间的间距较小，影响用户体验。

## 修复过程
1. **定位代码**：在`/Users/x/code/trae/compress/Views/MainWindow.axaml`文件中找到"来源与目标"区域的Grid布局代码（第26行）

2. **分析布局**：原Grid使用`RowDefinitions="Auto,Auto,Auto"`定义了3行，但行之间没有间距

3. **实施修复**：
   - 修改`RowDefinitions`为`RowDefinitions="Auto,5,Auto,5,Auto"`，在每行之间添加5个单位的固定间距
   - 更新控件的`Grid.Row`属性，将原第1行改为第2行，原第2行改为第4行，以跳过新增的间距行

## 修复代码
修改前：
```xaml
<Grid ColumnDefinitions="200,60,400,10,100,Auto" RowDefinitions="Auto,Auto,Auto">

    ...
    <!-- Row 1: TXT File Path -->

    <!-- Row 2: Output Path -->
    ...
</Grid>
```

修改后：
```xaml
<Grid ColumnDefinitions="200,60,400,10,100,Auto" RowDefinitions="Auto,5,Auto,5,Auto">
    <!-- Row 0: Source Mode and Save Path -->
    ...
    <!-- Row 2: TXT File Path -->

    ...

```

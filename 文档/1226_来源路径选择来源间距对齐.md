# 来源路径、选择来源之间应该有一点空白，而且应该和下方的文本框和按钮对齐

## 问题
用户要求来源路径和选择来源按钮之间应该有一点空白，而且应该和下方的文本框和按钮对齐。

## 解决方案
在 MainWindow.axaml 中调整Grid布局，增加空白列并确保来源部分和目的地部分的对齐。

### 修改内容

#### 1. 主Grid布局调整
将Grid的列定义从5列改为6列：
```xml
<!-- 修改前 -->
<Grid ColumnDefinitions="200,60,400,100,Auto" RowDefinitions="Auto,Auto,Auto">

<!-- 修改后 -->
<Grid ColumnDefinitions="200,60,400,10,100,Auto" RowDefinitions="Auto,Auto,Auto">
```

列定义说明：
- 第0列：宽度200（用于下拉列表）
- 第1列：宽度60（用于"同上"按钮）
- 第2列：宽度400（用于文本框）
- 第3列：宽度10（新增的空白列，提供间距）
- 第4列：宽度100（用于按钮）
- 第5列：Auto（用于输出大小文本）

#### 2. 来源部分控件调整
```xml
<!-- Source Mode Selection -->
<ComboBox Grid.Row="0" Grid.Column="0" SelectedIndex="{Binding SourceMode}">
    <ComboBoxItem Content="从txt读取要解压的文件："/>
    <ComboBoxItem Content="压缩此文件夹内所有文件："/>
</ComboBox>
<TextBox Grid.Row="0" Grid.Column="2" Text="{Binding SourcePath}" Watermark="来源路径"/>
<Button Grid.Row="0" Grid.Column="4" Content="选择来源" Command="{Binding BrowseSourceCommand}"/>
```

- 下拉列表：第0列
- 来源路径文本框：第2列
- 选择来源按钮：第4列（通过第3列的10像素空白与文本框分隔）

#### 3. 目的地部分Grid调整
```xml
<!-- Output Path -->
<Grid Grid.Row="2" Grid.Column="0" Grid.ColumnSpan="6" ColumnDefinitions="200,60,400,10,100,Auto">
    <TextBlock Grid.Column="0" Text="目的地：" VerticalAlignment="Center"/>
    <Button Grid.Column="0" Content="同上" Command="{Binding SetOutputSameAsSourceCommand}" 
            HorizontalAlignment="Right" Width="60" VerticalAlignment="Center"/>
    <TextBox Grid.Column="2" Text="{Binding OutputPath}" VerticalAlignment="Center"/>
    <Button Grid.Column="4" Content="选择目录" Command="{Binding BrowseOutputCommand}" VerticalAlignment="Center"/>
    <TextBlock Grid.Column="5" Text="{Binding OutputSizeText}" VerticalAlignment="Center" Foreground="Blue"/>
</Grid>
```

- Grid.ColumnSpan从5改为6（适应新的列数）
- ColumnDefinitions与主Grid保持一致（6列布局）
- 选择目录按钮：第4列（与选择来源按钮对齐）
- 输出大小文本框：第5列

### 效果
- 来源路径和选择来源按钮之间有10像素的空白
- 选择来源按钮和选择目录按钮水平对齐
- 来源路径文本框和输出路径文本框水平对齐
- 整体布局更加整齐美观

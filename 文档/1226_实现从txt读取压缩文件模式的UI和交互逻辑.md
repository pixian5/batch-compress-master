# 用户问题
下拉列表选择【从txt读取要压缩的文件】后，选择来源按钮的文字变成选txt。在这一行下面增加一行，有3列：
- 文字，待压缩/解压文件保存路径；
- 文本框，用户输入路径。文本框与上一行文本框水平对齐；
- 按钮，选择目录。
当用户点击选txt按钮后，选择密码文件，这个密码文件的文件名没有路径，所以拼接上面文本框的路径，注意，如果文本框用户没有输入目录结尾符号，如/，程序自动补上。
如果文本框没内容，用户点击选txt按钮后立即提示选择待解压文件保存目录，确定、取消。当用户点击确定后，模拟点击按钮选择目录，把路径输入文本框。然后再弹出提示：选择密码本txt文件，然后让用户选择文件位置，路径加入选txt按钮左侧的文本框。

# 实现内容

## 1. UI布局修改

### 1.1 动态按钮文字
- 在`MainWindowViewModel.cs`中添加了`BrowseSourceButtonText`计算属性，根据`SourceMode`动态返回按钮文字
- 在`MainWindow.axaml`中将按钮内容绑定到`BrowseSourceButtonText`属性
- 当`SourceMode=0`（从txt读取）时，按钮文字显示为"选txt"
- 当`SourceMode=1`（压缩文件夹）时，按钮文字显示为"选择来源"

### 1.2 新增保存路径行
在来源选择行下方新增一行，包含以下元素：
- 文字标签："待压缩/解压文件保存路径："
- 文本框：绑定到`SaveFilePath`属性，与上一行文本框水平对齐，宽度400
- 按钮："选择目录"，绑定到`BrowseSaveFileCommand`命令

## 2. ViewModel修改

### 2.1 新增属性和命令
- `SaveFilePath`：保存用户选择的待压缩/解压文件保存路径
- `BrowseSaveFileCommand`：处理选择目录按钮的点击事件
- `BrowseSourceButtonText`：动态生成按钮文字

### 2.2 事件处理
- 在`OnSourceModeChanged`中添加了对`BrowseSourceButtonText`的通知

## 3. View层修改

### 3.1 实现BrowseSaveFileAsync方法
使用Avalonia的`StorageProvider`打开文件夹选择对话框，允许用户选择保存目录，并将选择的路径设置到`SaveFilePath`属性。

### 3.2 实现复杂交互逻辑（BrowseSourceAsync方法）
1. **检查保存路径**：当用户点击"选txt"按钮时，首先检查`SaveFilePath`是否为空
2. **提示选择目录**：如果保存路径为空，弹出提示对话框，询问用户是否选择保存目录
3. **模拟点击按钮**：如果用户点击"确定"，自动调用`BrowseSaveFileAsync`方法打开目录选择对话框
4. **补全路径分隔符**：如果用户输入的保存路径不以目录分隔符结尾，自动补全
5. **选择密码本文件**：提示用户选择密码本txt文件
6. **拼接完整路径**：将选择的密码本文件名与保存路径拼接，生成完整路径并设置到`SourcePath`属性

### 3.3 实现自定义对话框
由于Avalonia没有内置的`MessageBox`类，实现了两个自定义对话框方法：
- `ShowMessageBoxAsync`：显示只有"确定"按钮的提示对话框
- `ShowOkCancelMessageBoxAsync`：显示包含"确定"和"取消"按钮的提示对话框

## 4. 测试文件
创建了测试文件目录`test_files/`，包含以下文件：
- `test_file_1.txt`：测试文本文件1
- `test_file_2.txt`：测试文本文件2
- `test_file_3.txt`：测试文本文件3
- `file_list.txt`：密码本文件，奇数行文件名，偶数行密码

# 技术要点

1. **Avalonia UI框架**：使用XAML定义界面，通过数据绑定实现UI与ViewModel的交互
2. **MVVM模式**：使用CommunityToolkit.Mvvm实现属性通知和命令绑定
3. **动态UI**：根据数据模型动态变更UI元素的内容和可见性
4. **文件操作**：使用Avalonia的StorageProvider进行文件和目录选择
5. **路径处理**：使用System.IO.Path类处理文件路径，确保路径格式正确
6. **异步编程**：使用async/await处理异步UI操作，避免阻塞主线程
7. **自定义对话框**：实现了符合Avalonia规范的自定义对话框组件

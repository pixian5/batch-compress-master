# 处理速度显示改为整数格式

## 修改内容
将处理速度的显示格式从保留两位小数改为只显示整数部分。

## 具体修改
在 `Views/MainWindow.axaml` 中修改了处理速度的绑定格式：

**修改前：**
```xml
<TextBlock Text="{Binding ProcessingSpeedMBPerSecond, StringFormat={}{0:F2}MB/秒}" Foreground="Blue" FontSize="16"/>
```

**修改后：**
```xml
<TextBlock Text="{Binding ProcessingSpeedMBPerSecond, StringFormat={}{0:0}MB/秒}" Foreground="Blue" FontSize="16"/>
```

## 效果
处理速度现在显示为整数MB/s，例如："25MB/秒" 而不是 "25.43MB/秒"。

# 官方 7z 支持

GPT-5，2026-08-06：本文记录 7z 后端的依赖来源、实现边界和验证方法，供后续打包与排障使用。

## 依赖

项目保存 7-Zip 官方 25.01 独立命令行程序及随包许可证：

- `tools/7zip/macos/7zz`：macOS universal。
- `tools/7zip/linux-x64/7zz`：Linux x64。
- `tools/7zip/linux-arm64/7zz`：Linux ARM64。
- Windows 预留 `tools/7zip/windows-x64/7z.exe`，当前还会检测标准 `Program Files/7-Zip/7z.exe` 安装位置。

归档下载来源为 `https://www.7-zip.org/`。原始归档 SHA-256：

- macOS：`26aa75bc262bb10bf0805617b95569c3035c2c590a99f7db55c7e9607b2685e0`
- Linux x64：`4ca3b7c6f2f67866b92622818b58233dc70367be2f36b498eb0bdeaaa44b53f4`
- Linux ARM64：`39c5140f02ce4436599303c59a149f654cb1bbc47cdc105a942120d747ae040d`

## 行为

`ArchiveEngineRouter` 将 RAR/ZIP 交给 WinRAR/RAR，将 7z 交给官方 `7zz`。7z 支持压缩级别、固实模式、密码及文件名加密、分卷、临时目录、创建后测试与三种既有文件策略。RAR 专属的恢复记录、快速打开和注释文件不会传给 7zz。

参数全部通过 `ProcessStartInfo.ArgumentList` 逐项添加。stdout 与 stderr 并行异步读取；取消会终止整个进程树。原始进程输出明确不进行密码脱敏，也不把密码替换为 `***`。

## 打包与验证

`scripts/package-macos.sh` 将 macOS `7zz`、许可证、说明和历史文件复制到 `.app/Contents/MacOS/tools/7zip/macos/`，再整体签名。回归测试会用该官方程序真实创建带密码 7z、执行归档测试、解压并核对文件内容。

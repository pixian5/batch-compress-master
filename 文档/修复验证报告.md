## 技术方案

### 核心改动
采用 **动态计算属性 + PropertyChanged 通知** 的方案

### 修改的文件
1. `ViewModels/MainWindowViewModel.cs`
   - 添加 `CompressionLevelOptions` 计算属性
   - 添加 `ExistingFileModeOptions` 计算属性
   - 增强 `OnSelectedLanguageChanged()` 通知机制

2. `Views/MainWindow.axaml`
   - 压缩级别下拉列表：改用 ItemsSource 绑定
   - 已存在文件处理下拉列表：改用 ItemsSource 绑定

### 关键代码片段

```csharp
public List<string> CompressionLevelOptions => new()
{
    L.NoCompression,
    L.Light,
    L.Fast,
    L.Standard,
    L.Better,
    L.Best
};

partial void OnSelectedLanguageChanged(string value)
{
    Localization.CurrentLanguage = value;
    OnPropertyChanged(nameof(CompressionLevelOptions));  // 触发绑定更新
}
```

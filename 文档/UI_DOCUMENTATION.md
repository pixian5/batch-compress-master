# 用户界面文档 - 按钮、流程与步骤详解

## 界面布局概览

批量压缩解压工具的主界面分为以下几个主要区域：

1. **源文件选择区**
2. **目标路径设置区**
3. **压缩选项配置区**
4. **操作按钮区**
5. **进度显示区**
6. **日志输出区**

## 详细组件说明

### 一、源文件选择区

#### 1.1 【从哪儿来】下拉框 (cbFrom)
**功能**: 选择文件来源方式
- **选项1**: "从此txt读取要压缩的文件" - 从文本文件读取文件列表
- **选项2**: "压缩此文件夹内所有文件" - 选择一个文件夹

**使用场景**:
- 当需要压缩指定的若干文件时，选择txt方式
- 当需要压缩整个文件夹的所有内容时，选择文件夹方式

**工作流程**:
```
选择"从txt读取"
    ↓
点击【选txt】按钮
    ↓
选择txt文件（格式：每行一个文件名和密码交替）
    ↓
自动填充到待处理列表
```

#### 1.2 【从哪儿来/选txt】按钮 (btnSource)
**功能**: 打开文件/文件夹选择对话框

**按钮文本变化**:
- 当选择"txt"模式时，显示"选txt"
- 当选择"文件夹"模式时，显示"从哪儿来"

**操作步骤**:
1. 点击按钮
2. 选择对应的txt文件或文件夹
3. 系统自动读取并填充文件列表

**txt文件格式要求**:
```
文件1
密码1
文件2
密码2
...
```
- 奇数行：文件名（不含路径和后缀）
- 偶数行：对应的密码

#### 1.3 源路径文本框 (tbSource)
**功能**: 显示选中的文件夹路径或txt文件路径

**特性**:
- 支持拖放操作
- 自动处理路径中的双反斜杠
- 文本改变时自动触发刷新

**提示文字**: "待解压文件们所在文件夹"

#### 1.4 待处理文件列表 (rtbSource)
**功能**: 显示所有待压缩/解压的文件完整路径

**格式**:
```
/path/to/folder/file1.txt
/path/to/folder/file2.txt
/path/to/folder/subfolder
...
```

**特性**:
- 支持手动编辑
- 每行一个文件或文件夹的完整路径
- 空行会被自动跳过

#### 1.5 【刷新】按钮 (btnRefresh)
**功能**: 重新读取源路径，更新待处理文件列表

**快捷键**: F5

**使用时机**:
- 源路径内容有变化
- 修改了过滤选项（如"不压缩【已压缩】"）
- 需要重新统计文件

### 二、目标路径设置区

#### 2.1 【到哪儿去】按钮 (btnSavePath)
**功能**: 选择压缩/解压后的文件保存位置

**操作步骤**:
1. 点击按钮
2. 在文件夹浏览对话框中选择目标文件夹
3. 路径自动填充到文本框

#### 2.2 目标路径文本框 (tbSavePath)
**功能**: 显示和编辑目标保存路径

**特性**:
- 文本改变时自动更新临时文件夹路径
- 实时计算目标文件夹已有的压缩文件大小
- 自动处理路径格式

#### 2.3 【打开目标文件夹】按钮
**功能**: 在资源管理器中打开目标文件夹

**使用场景**:
- 查看压缩结果
- 管理压缩文件

### 三、压缩选项配置区

#### 3.1 密码设置

##### 【随机密码】复选框 (Cbpw)
**功能**: 启用/禁用随机密码生成

**选中状态**:
- 每个文件使用独立的MD5哈希密码
- 密码格式: `MD5(文件名+盐1) + MD5(文件名+盐2)`
- 隐藏自定义密码输入框

**未选中状态**:
- 显示密码输入框和设置按钮
- 所有文件使用相同的自定义密码
- 留空则不加密

##### 密码输入框 (tbPW)
**功能**: 输入自定义密码

**特性**:
- 仅在未选中"随机密码"时显示
- 应用于所有待压缩文件
- 空格会被自动删除

##### 【设置密码/解锁高级功能】按钮 (btnPW)
**功能**: 
- 一般用户：设置密码
- 高级用户：解锁高级功能

**解锁密码**:
```
MD5(当前年份第几天 + "我爱") + MD5(当前年份第几天 + "胖田田")
```
例如：第100天的解锁密码由当天日期生成

**解锁后可用功能**:
- 自定义压缩文件扩展名
- 设置分卷大小
- 添加注释文件
- 添加附件
- 完成后关机

#### 3.2 压缩格式设置

##### 【压缩格式】文本框 (exTension)
**功能**: 设置压缩文件的扩展名

**默认值**: "rar"

**支持格式**:
- rar - WinRAR格式（推荐）
- zip - ZIP格式
- 7z - 仅支持解压，不支持压缩

**注意**:
- 选择7z格式会弹出提示，建议改为rar或zip
- 扩展名会自动添加点号

#### 3.3 压缩率设置

##### 【压缩率】下拉框 (cbRate)
**功能**: 设置压缩级别

**选项**:
- 0 - 不压缩（仅打包，速度最快）
- 1 - 轻度压缩（推荐）
- 2 - 标准压缩
- 3 - 良好压缩
- 4 - 最大压缩
- 5 - 极限压缩

**提示**:
- 压缩率越高，占用资源越多
- 但文件大小不一定明显减小
- 推荐使用"不压缩"或"轻度压缩"

**特殊规则**:
- "不压缩"模式下，"固实"选项无效

#### 3.4 固实压缩

##### 【固实】复选框 (CbSolid)
**功能**: 启用固实压缩模式

**固实压缩特点**:
- 将多个文件视为连续数据流压缩
- 可获得更高的压缩率
- 字典大小设为32MB

**注意事项**:
- 部分网盘不支持在线解压固实压缩文件
- 与"不压缩"模式冲突
- 解压单个文件需要读取整个压缩包

#### 3.5 分卷压缩

##### 【分卷】复选框 (cbDivide)
**功能**: 启用分卷压缩

**分卷大小设置**:
- 文本框 (tbVolume)：输入大小数值
- 单位下拉框 (cbGMK)：选择单位
  - g - GB
  - m - MB  
  - k - KB

**使用场景**:
- 文件过大需要分割
- 受存储介质限制（如FAT32的4GB限制）
- 便于网络传输

**分卷文件命名**:
```
原文件.rar -> 
  原文件.part01.rar
  原文件.part02.rar
  原文件.part03.rar
  ...
```

#### 3.6 文件处理选项

##### 【存在时】下拉框 (cbExist)
**功能**: 设置目标文件已存在时的处理方式

**选项**:
- 0 - 跳过（不覆盖，不压缩/解压）
- 1 - 更新（仅当源文件较新时）
- 2 - 覆盖（直接替换）

**默认值**: 覆盖

##### 【压缩后删除源文件】复选框 (CbDel)
**功能**: 压缩/解压成功后删除源文件

**警告**: 
- 删除操作不可恢复
- 建议先测试确认无误再使用

##### 【压缩后移动到"已压缩"】复选框 (cbMoveSource)
**功能**: 压缩/解压成功后移动源文件到"【已压缩】"或"【已解压】"文件夹

**移动规则**:
- 在源文件所在目录创建子文件夹
- 移动而非复制（节省空间）
- 如果目标位置已存在同名文件，则不移动

**互斥关系**: 与"删除源文件"互斥，只能选一个

##### 【不压缩含"已压缩"的文件】复选框 (cbYiYaSuo)
**功能**: 跳过文件名包含"【已压缩】"或"【已解压】"的文件

**使用场景**:
- 避免重复压缩
- 跳过已处理的文件

#### 3.7 高级选项（需解锁）

##### 【快速打开信息】复选框 (cbQucikOpen)
**功能**: 添加快速打开信息到压缩文件

**效果**: 加快大压缩文件的打开速度

##### 【校验】复选框 (cbCheck)
**功能**: 压缩完成后自动校验文件完整性

**用途**: 确保压缩文件没有损坏

##### 【恢复记录】文本框 (tbRec)
**功能**: 设置恢复记录大小（百分比）

**范围**: 0-100

**作用**: 即使压缩文件部分损坏，也有可能恢复数据

##### 【注释文件】复选框和路径 (cbNotice, tbNotice)
**功能**: 为压缩文件添加注释

**格式**: 指定一个文本文件路径

**用途**: 在压缩文件中添加说明信息

##### 【临时文件夹】文本框 (tbTmp)
**功能**: 设置压缩/解压时使用的临时文件夹

**默认**: 与目标路径相同

**用途**: 
- 指定高速磁盘提升性能
- 避免系统盘空间不足

##### 【添加附件】区域 (enclosureList, btnAddFile)
**功能**: 在压缩文件中添加联系方式或说明文件

**使用方法**:
1. 在文本框输入要创建的文件夹名称
2. 或点击【添加文件】按钮选择文件夹
3. 压缩时会在每个文件夹中创建这些文件夹

**默认内容**:
```
【解压密码】发邮件给 qgkc520@Gmail.com
【解压密码】微信号：i17269637581
【解压密码】QQ号：2027123419
...
```

#### 3.8 其他设置

##### 【压到指定大小】文本框 (tbSize)
**功能**: 设置压缩/解压的目标大小（GB）

**作用**:
- 达到指定大小后自动停止
- 用于控制输出文件总量

**示例**: 输入"666"表示压缩到666GB后停止

##### 【完成后关机】复选框 (cbShutdown)
**功能**: 操作完成后自动关机

**流程**:
1. 操作完成后执行 `shutdown -s`
2. 弹出对话框询问是否取消
3. 点击确定则执行 `shutdown -a` 取消关机

**使用场景**: 处理大量文件，晚上运行

### 四、操作按钮区

#### 4.1 【压缩！】按钮 (btnRun)
**功能**: 开始批量压缩操作

**执行流程**:
```
1. 禁用压缩和解压按钮
2. 创建取消令牌源
3. 创建进度报告器
4. 显示"压缩中..."状态
5. 异步执行压缩操作
6. 逐个处理文件列表中的文件
   a. 检查文件是否存在
   b. 跳过已压缩文件（如果勾选）
   c. 生成密码（随机或自定义）
   d. 创建联系方式文件夹（如果需要）
   e. 构建WinRAR命令参数
   f. 调用WinRAR执行压缩
   g. 处理压缩结果（删除/移动源文件）
   h. 更新进度和统计
   i. 检查是否达到目标大小
7. 显示完成信息
8. 重新启用按钮
```

**命令行参数示例**:
```
A -ep1 -IBCK -o+ -SCf "/path/to/output/file.rar" "/path/to/input/file" -p密码 -v300m -m1 -rr0 -w"/path/to/temp"
```

**参数说明**:
- `A`: 添加文件到压缩包
- `-ep1`: 排除基础文件夹
- `-IBCK`: 后台运行
- `-o+`: 覆盖已存在文件
- `-SCf`: 使用UTF-8文件名
- `-p`: 设置密码
- `-v`: 分卷大小
- `-m`: 压缩率
- `-rr`: 恢复记录
- `-w`: 临时文件夹

#### 4.2 【解压！】按钮 (Btndepress)
**功能**: 开始批量解压操作

**执行流程**:
```
1. 禁用压缩和解压按钮
2. 创建取消令牌源和进度报告器
3. 显示"解压中..."状态
4. 计算待解压文件总大小和数量
5. 异步执行解压操作
6. 逐个处理压缩文件
   a. 检查文件是否存在
   b. 跳过已解压文件（如果勾选）
   c. 处理分卷文件（只解压第一卷）
   d. 获取密码（从txt或随机生成）
   e. 构建WinRAR解压命令
   f. 调用WinRAR执行解压
   g. 处理解压结果（删除/移动源文件）
   h. 更新进度和统计
   i. 检查是否达到目标大小
7. 显示完成信息
8. 重新启用按钮
```

**命令行参数示例**:
```
-IBCK x -o+ -p"密码" "/path/to/input/file.rar" "/path/to/output/"
```

**参数说明**:
- `-IBCK`: 后台运行
- `x`: 解压并保留路径
- `-o+`: 覆盖已存在文件
- `-p`: 解压密码

#### 4.3 【取消】按钮 (btnCancel)
**功能**: 取消当前正在进行的压缩/解压操作

**工作原理**:
- 调用 `CancellationTokenSource.Cancel()`
- 当前文件处理完成后停止
- 不会强制中断WinRAR进程

**显示**: "正在取消，等待当前文件解压完成..."

#### 4.4 【帮助】按钮 (btnhelp)
**功能**: 显示使用帮助信息

**帮助内容包括**:
1. 基本使用说明
2. 密码设置说明
3. 压缩类型选择
4. 固实压缩注意事项

#### 4.5 【清空】按钮 (btnreset)
**功能**: 清除所有文本框和列表的内容

**清空内容**:
- 待处理文件列表
- 成功日志
- 失败日志
- 命令历史

#### 4.6 【刷新】按钮 (btnRefresh)
**功能**: 刷新文件列表

**快捷键**: F5

#### 4.7 【缩小/放大】按钮 (btnZoom)
**功能**: 切换窗口大小

**状态**:
- "缩小": 窗口最大化 → 点击后恢复正常大小
- "放大": 窗口正常 → 点击后最大化

#### 4.8 【隐藏】按钮 (btnHide)
**功能**: 隐藏主窗口到系统托盘

**恢复方法**: 双击系统托盘图标

#### 4.9 【查询密码】按钮 (btngetpw)
**功能**: 根据文件名计算随机密码

**使用步骤**:
1. 在文件名输入框输入文件名
2. 点击【查询密码】
3. 系统计算多种密码算法的结果
4. 密码自动复制到剪贴板

**输出示例**:
```
文件名.rar的密码是：
MD5gb2312 5 2 tt
[密码1]
gb2312 592 ptt 1314
[密码2]
UTF874 5 2 tt
[密码3]
UTF874 592 ptt 1314
[密码4]
UTF878 592ptt1314 592pnn1314 7,8
[密码5]
```

#### 4.10 【清空命令】按钮 (btnClearAll)
**功能**: 清空命令历史列表

#### 4.11 【清空列表】按钮 (btnClearSource)
**功能**: 清空待处理文件列表

#### 4.12 【统计】标签 (lsum)
**功能**: 点击显示文件统计信息

**显示内容**:
```
文件/文件夹/无效： X/Y/Z
```

## 完整操作流程示例

### 流程一：压缩整个文件夹

```
步骤1: 启动程序（自动请求管理员权限）
步骤2: 选择"压缩此文件夹内所有文件"
步骤3: 点击【从哪儿来】，选择源文件夹
步骤4: 点击【到哪儿去】，选择目标文件夹
步骤5: 配置选项
  - 勾选【随机密码】
  - 选择【压缩率】为"轻度压缩"
  - 勾选【固实】（如果网盘支持）
  - 根据需要设置【分卷】
  - 选择【存在时】处理方式
步骤6: 点击【压缩！】
步骤7: 观察进度显示
  - 当前文件
  - 成功数量
  - 已压缩大小
步骤8: 等待完成或点击【取消】中断
步骤9: 查看日志
  - 成功列表：所有压缩成功的文件
  - 失败列表：失败原因
  - 命令历史：实际执行的命令
步骤10: 点击【打开目标文件夹】查看结果
```

### 流程二：从txt文件解压并使用密码

```
步骤1: 准备密码txt文件
  格式:
    文件1
    密码1
    文件2
    密码2
```

## 错误处理和提示

### 常见错误提示

1. **"请安装 WinRAR 5.0 以上版本"**
   - 原因: 未安装WinRAR或版本过低
   - 解决: 安装WinRAR 5.0+

2. **"不存在以下文件"**
   - 原因: 文件列表中的文件不存在
   - 解决: 检查文件路径，刷新列表

3. **"555，压缩失败了"**
   - 显示WinRAR错误码和说明
   - 根据错误码采取相应措施

4. **"移动/重命名失败，文件已存在"**
   - 原因: 【已压缩】文件夹中已有同名文件
   - 解决: 手动处理或选择覆盖模式

### WinRAR 错误码对照表

| 错误码 | 说明 | 处理建议 |
|--------|------|----------|
| 0 | 成功 | 无需处理 |
| 1 | 警告（有小错） | 通常可以忽略 |
| 2 | 致命错误 | 检查文件和权限 |
| 3 | 数据损坏 | 文件可能已损坏 |
| 4 | 文件已锁定 | 关闭占用文件的程序 |
| 5 | 不能写 | 检查磁盘空间和权限 |
| 6 | 打不开 | 检查文件是否存在 |
| 7 | 命令行错误 | 检查参数设置 |
| 8 | 内存不够 | 关闭其他程序 |
| 9 | 创建不了文件 | 检查目标路径 |
| 10 | 没解压 | 文件可能已存在 |
| 11 | 密码错误 | 检查密码是否正确 |
| 255 | 用户中断 | 主动取消 |

## 性能优化建议

### 提升速度
1. 选择"不压缩"或"轻度压缩"
2. 不勾选"固实"
3. 将临时文件夹设置在SSD上
4. 关闭校验选项

### 节省空间
1. 选择"极限压缩"
2. 勾选"固实"
3. 不添加恢复记录

### 兼容性优先
1. 选择"轻度压缩"
2. 不勾选"固实"
3. 不使用分卷（除非必要）

## 注意事项

1. **管理员权限**: 程序需要管理员权限，会自动请求UAC提权
2. **WinRAR依赖**: 必须安装WinRAR 5.0+
3. **固实与在线解压**: 固实压缩的文件部分网盘无法在线解压
4. **密码安全**: 随机密码基于文件名生成，需要保存密码或记住算法
5. **分卷文件**: 只需要解压第一卷，其他卷会自动使用
6. **文件删除**: 删除源文件操作不可恢复，请谨慎使用
7. **路径格式**: 支持中文路径，自动处理路径分隔符
8. **取消操作**: 取消后会等待当前文件处理完成才停止

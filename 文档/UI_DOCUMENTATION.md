# 界面说明

主窗口提供来源、目标、压缩选项、后处理、操作与日志区域。控件通过 `MainWindowViewModel` 双向绑定，运行期间会禁用冲突命令以避免并发批处理。

- 来源：目录扫描、TXT 列表和拖放。系统元数据、垃圾箱目录和锁文件会被跳过。
- 目标：通过 Avalonia 原生文件夹选择器选择；空目标不会启动任务。
- 压缩选项：格式仅为 RAR/ZIP；密码、压缩率、固实、分卷、恢复记录、校验、注释和临时目录均可配置。
- 后处理：删除、移动、跳过已处理、附件目录、大小限制、关机与取消关机。
- 日志：源列表、成功、失败和命令日志可独立清空。命令日志显示原始进程输出，包含密码时不会脱敏。
- 提示：交互控件使用黄色 Tooltip；快捷键和拖放操作在界面中可直接使用。

窗口位置和尺寸会持久化。隐藏窗口后依然保留托盘入口；普通窗口关闭会退出进程。

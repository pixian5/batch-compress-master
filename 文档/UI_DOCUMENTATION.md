# 界面说明

> 状态：2026-11-05 复核到 `VERSION 0.7.6`。本文描述界面行为；
> 具体控件结构以 `Views/MainWindow.axaml` 与 `ViewModels/MainWindowViewModel.cs` 为准。
> 早期界面微调记录（`0726-*` / `1226-*` 等）是历史快照，不能当作当前布局依据，见
> [界面与交互经验](../经验/10-界面与交互.md)。

主窗口提供来源、目标、压缩选项、后处理、操作与日志区域。控件通过 `MainWindowViewModel`
双向绑定，运行期间禁用冲突命令以避免并发批处理。业务逻辑不放在 AXAML 代码隐藏里。

- **来源**：目录扫描、TXT 列表和拖放。系统元数据、垃圾箱目录与锁文件会被跳过；
  切换到「从 TXT 读取」时，选择来源按钮改为选文件而不是目录。
- **目标**：通过 Avalonia 原生文件夹选择器选择；空目标不会启动任务。
- **压缩选项**：可创建 RAR、ZIP、7z、TAR、GZIP、BZIP2、XZ、WIM；
  密码、压缩率、固实、分卷、恢复记录、校验、注释、临时目录、并发度均可配置。
  恢复记录、快速打开、锁定与注释仅对 RAR 生效，不会传给 `7zz`。
- **后处理**：删除、移动、跳过已处理、附件目录、大小限制、关机与取消关机。
- **日志**：源列表、成功、失败和命令日志可独立清空。命令日志显示完整命令行及原始进程输出，
  **包含密码时不会脱敏**，这是既定诊断行为。
- **提示**：交互控件使用黄色 Tooltip；快捷键和拖放操作在界面中可直接使用。

窗口位置和尺寸会持久化。普通关闭窗口会退出应用；「隐藏到托盘」和托盘「显示/隐藏」
只改变主窗口可见性。macOS 的托盘由随应用包分发的原生帮助进程提供，
切换界面语言时主程序会重启它才能刷新菜单文案；其它平台重建原生菜单。

界面文案支持五语言（简体中文、繁體中文、English、日本語、Deutsch），
新增用户可见词条必须五套资源同步补齐。

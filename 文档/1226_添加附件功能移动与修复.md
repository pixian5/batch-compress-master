# 把添加附件移动到压缩选项和后处理选项之间单独一列，修复勾选后出现的列表为灰色不可编辑的问题

## 问题分析

用户要求将"添加附件"功能从后处理选项中分离出来，移动到压缩选项和后处理选项之间作为单独一列，并修复勾选"添加附件"后列表为灰色不可编辑的问题。

## 解决方案

在 MainWindow.axaml 中进行了以下修改：

### 1. 布局结构调整

**Grid布局从2列改为3列**：
```xml
<!-- 修改前 -->
<Grid ColumnDefinitions="*,*" ColumnSpacing="10">

<!-- 修改后 -->
<Grid ColumnDefinitions="*,*,*" ColumnSpacing="10">
```

### 2. 附件选项中间列创建

**新增中间列用于附件选项**：
```xml
<!-- Middle Column: Attachment Options -->
<StackPanel Grid.Column="1" Spacing="8">
    <TextBlock Text="附件选项" FontWeight="Bold" FontSize="14"/>
    
    <StackPanel Orientation="Horizontal" Spacing="15">
        <CheckBox Content="添加附件" IsChecked="{Binding AddEnclosures}"/>
    </StackPanel>
    
    <!-- Enclosure List -->
    <StackPanel IsVisible="{Binding AddEnclosures}">
        <TextBlock Text="附件目录列表（每行一个）：" Margin="0,5,0,5"/>
        <TextBox Text="{Binding EnclosureList}" Height="80" AcceptsReturn="True" TextWrapping="Wrap"
                 IsEnabled="{Binding AddEnclosures}"/>
    </StackPanel>
</StackPanel>
```

### 3. 后处理选项列调整

**从后处理选项中移除添加附件功能**：
```xml
<!-- 修改前 -->
<StackPanel Orientation="Horizontal" Spacing="15">
    <CheckBox Content="添加附件" IsChecked="{Binding AddEnclosures}"/>
    <CheckBox Content="完成后关机" IsChecked="{Binding ShutdownAfterComplete}"/>
</StackPanel>

<!-- 修改后 -->
<StackPanel Orientation="Horizontal" Spacing="15">
    <CheckBox Content="完成后关机" IsChecked="{Binding ShutdownAfterComplete}"/>
</StackPanel>
```

### 4. 修复不可编辑问题

**修改IsEnabled绑定**：
```xml
<!-- 修改前 -->
<TextBox Text="{Binding EnclosureList}" Height="80" AcceptsReturn="True" TextWrapping="Wrap"
         IsEnabled="{Binding AdvancedFeaturesUnlocked}"/>

<!-- 修改后 -->
<TextBox Text="{Binding EnclosureList}" Height="80" AcceptsReturn="True" TextWrapping="Wrap"
         IsEnabled="{Binding AddEnclosures}"/>
```

## 效果

1. **布局变化**：
   - 现在有三列：压缩选项（左）、附件选项（中）、后处理选项（右）
   - 整体布局更加清晰，功能分组合理

2. **功能修复**：
   - 勾选"添加附件"后，附件目录列表自动变为可编辑状态
   - 取消勾选"添加附件"后，附件目录列表隐藏

3. **视觉效果**：
   - 保持了与其他选项一致的视觉风格
   - 新增"附件选项"标题，增强可读性
   - 控件间距和布局保持一致

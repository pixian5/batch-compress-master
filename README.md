# 批量压缩解压工具

一个使用WinRAR进行批量压缩和解压的Windows应用程序。

## 最新优化

1. **UI与后台处理分离** - 使用异步任务处理，确保UI不会在压缩/解压过程中冻结
2. **进度报告** - 实时显示压缩/解压进度
3. **操作可取消** - 添加取消按钮，支持中断长时间运行的操作
4. **多线程支持** - 利用Task和异步/等待模式提高性能
5. **稳定性增强** - 适当的错误处理和资源管理

## 主要功能

- 批量压缩文件或文件夹
- 批量解压文件
- 支持密码保护
- 支持分卷压缩
- 自定义压缩选项
- 支持不同压缩格式(RAR, 7z, ZIP等)

## 使用说明

需要安装WinRAR 5.0或更高版本。

## 开发环境

- Windows操作系统
- Visual Studio 2022或更高版本
- .NET 8

## 编译说明

在Visual Studio中打开项目解决方案`批量压缩.sln`，然后编译项目。
